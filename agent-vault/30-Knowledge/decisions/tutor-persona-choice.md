# 결정: 강사 페르소나·역할 (사용자 확정 2026-09-26)

| 항목 | 결정 | 이유 |
|---|---|---|
| 페르소나 수 | 단일(목소리만 Voice Profile 로 교체) | 추가 기획안 §45 "페르소나와 Voice 독립". 일관성 관리 단순 |
| 성격 | 교정에 철저 + 일본인 원어민 설정 | 사용자 선택. 원어민 관점(교과서 vs 실제 표현) 설명 가능 |
| 언어 | 한국어 설명 + 일본어 대화(explainLang 으로 ja 전환 가능) | 초~중급 대상, 설명 부담 최소 |
| 이름 | 사용자 지정(`Profile.teacherName`, 기본 '선생님') | 캐릭터 고정보다 학습자 몰입 |
| 개발팀 편입 | 하지 않음(런타임 페르소나 전용, Claude Code 세션에선 사양 자문) | 기획서 "서브에이전트 구성" 나열은 역할정의 필요를 뜻한 것으로 해석, 사용자 유지 |
| 스케줄·커리큘럼 주체 | **강사**(A11 복습 판단, 3~7일) / 코드는 범위 강제·기록·균등 랜덤 추출·폴백 | 기획서 원문 + 사용자 피드백. 재현성은 코드 경계로 확보 |
| 반복 규칙 | 3일 고정 폐기 → 항목별 3~7일, 학습 횟수 DB 기록(`RepetitionItem`), 균등 랜덤, 오답·피드백 많은 항목 FOCUS(≤3일) | 사용자 원문 지시 |
| 타임아웃 | 현재 설계 유지(회화 12s fail-fast·잡 60~300s) | 기획서 5/10초는 체감 목표로 해석, 사용자 유지 |
| 청취 구간 반복·단어 메모·종료 지점 | 반영(레슨 1단계, ADD_WORD 제안, nextPreview) | 레퍼런스2 기획 반영 항목 누락 복구 |

**근거 파일**: `docs/design-spec.md` §0·§7-4·§8, `docs/design/learning-personalization-and-llm-data.md` §0·§2, `.claude/agents/tutor.md` v1, `docs/design/tutor-persona-validation.md`.
