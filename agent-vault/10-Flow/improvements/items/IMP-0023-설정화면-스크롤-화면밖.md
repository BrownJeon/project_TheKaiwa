## 현상

앱에서 설정화면이 스크롤을 계속 내리면 화면 밖까지 스크롤이 내려가.

## 기대하는 모습

화면이동에 대한 확인해줘

(설정 화면 끝에서 더 내려가지 않고, 하단 탭은 화면 맨 아래에 고정)

## 근거

![[IMP-0023-1.jpg]]
앱 1.0.2 다크 모드, 설정 맨 아래 '휴대폰 인식 진단' 카드(메모리 앱 511MB·Java 9MB, 파일 버전 2024-08-01-int8-v1, 플러그인 0.1.0·arm64-v8a, [다시 읽기][미리 불러오기]) 아래로 **하단 탭(회화·오늘·계획표·단어장·질문)이 화면 중간까지 올라와 있고 그 아래가 빈 영역**이다 — 페이지(또는 앱 셸) 전체가 화면 높이보다 길게 스크롤된다. "화면당 스크롤 1곳"(CLAUDE.md 모바일 UI 원칙) 위반으로 보인다.

## 분류 메모 (착수 때 Leader)

- 원인 미확인. 후보(검증 전): 1.0.2 네이티브 키보드 보정(task-021 — WebView 하단 margin = max(내비 바, 키보드))과 웹 `--kb-inset`·100dvh 의 이중 반영, 또는 설정 화면만 셸 밖 문서 스크롤. 1.0.1·웹 Chrome 에서도 재현되는지 먼저 확인.

## 재현 확인 (사용자, 2026-10-03 23:24)

> "크롬 웹, 앱에서도 동일하게 스크롤 문제가 발생해"

- **웹 Chrome·앱 둘 다 재현** → 네이티브 키보드 보정(task-021) 단독 원인 후보는 약해짐. 웹 쪽(설정 화면이 앱 셸 밖 문서 스크롤을 만드는 구조·`100dvh`·`min-height`) 원인이 유력. 재현 확인 완료 → 착수 가능.
