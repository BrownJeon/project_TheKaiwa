## 현상

단어장의 조건 필터가 현재 방식대로 되어 있어 조각속성별로 찾기 어려움.

## 기대하는 모습

조건필터는 조각속성(이름조각, 액션조각, 느낌조각, 꾸밈조각)별로

## 근거

## 분류 메모 (착수 때 Leader)

- 재확인: 유효. 현재 단어장 필터는 `category` 칩(예: 'N5 기초', 사용자 지정 문자열)뿐 — `listWords` where 절에 `chunkType` 조건이 없다(`modules/learning/vocab/words.ts` L241~). 조각 속성(`WordEntry.chunkType` = NAME·ACTION·FEELING·MODIFIER, 이름/액션/느낌/꾸밈 조각)은 데이터로 존재하고 상세 시트에서만 뱃지로 보인다(`CHUNK_LABEL`).
- 사실: 기본 단어 팩 50개 중 chunkType 채움 48개(NAME 16·ACTION 15·FEELING 9·MODIFIER 8), 미지정 2개. 직접 추가·교정 채택 단어는 chunkType 이 null 일 수 있어 필터에 '조각 미지정' 항목이 필요.
- 영향 파일: `words.ts`(필터 파라미터 `chunkType`), `src/app/api/v1/words/route.ts`·카테고리 집계, `CategoryChips`·`WordsScreen`, `docs/design/api-contract.md` #40, `docs/screens.md` §4. 규모 M. Leader 의견: 카테고리 칩을 대체할지(사용자 원문 "조각속성별로") 병행할지 결정 필요 — 사용자 질문 Q1. IMP-0003 과 한 task.

- 우선순위·순서는 사용자가 지정하지 않아 **Leader 권고 순서**(P1→P2→P3)를 잠정 채택했다. 사용자가 바꾸면 이 값을 고친다.
