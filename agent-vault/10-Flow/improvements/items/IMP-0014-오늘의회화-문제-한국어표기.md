## 현상

문제 단계에서 어떤 문제인지 한국어 표기가 없어 사용자가 파악하기 어려움.

## 기대하는 모습

문제 단계에서는 문제는 한국어로도 표기해서 어떤 문제인지는 사용자가 알수있도록 표기해줘

## 근거

## 분류 메모 (착수 때 Leader)

- 재확인: 부분 유효. 퀴즈 화면(`StageQuiz.tsx` L145)은 `q.promptKo ?? <일본어>` 로 그린다 — **`promptKo` 가 null 인 문제는 일본어만 나온다.** A4 스키마가 `promptKo` 를 null 허용으로 두고 `promptKo`·`promptJa` 중 하나만 있으면 통과시키기 때문(`schemas.ts` L293·400, `reviewMix.ts` 프롬프트 "최소 하나"). 응용·말하기(`application`·`speaking`)는 `promptKo` 필수라 한국어가 항상 있다.
- 영향 파일: `structuredResponse/schemas.ts`·`checks.ts`(quiz.promptKo 필수화), `prompts/reviewMix.ts` 등 A4 프롬프트(prompt-engineer), 회귀 픽스처, 이미 저장된 레슨은 null 인 채로 남음(화면에서 대체 표기 불가). 규모 S~M. Leader 의견: 스키마 버전을 올리는 변경(A4 v8)이라 Reviewer 가 스키마 일관성 감사. 사용자가 본 화면이 문제 단계(퀴즈)인지 응용 단계 문제 제시인지는 Q10 로 확인.

## 착수 결정 (사용자 답변, 2026-09-30)

- Q10 "모든 단계" — 한국어 표기를 레슨 모든 단계의 문제 문장에 적용. A4 v8(promptKo 필수).
- 우선순위·순서는 사용자가 지정하지 않아 **Leader 권고 순서**(P1→P2→P3)를 잠정 채택했다. 사용자가 바꾸면 이 값을 고친다.
