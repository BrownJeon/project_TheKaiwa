## 설계 참고 — 조각공부법 레퍼런스 분석 (Leader, 2026-10-21)

- **출처**: TheThinker 레퍼런스 `cmvgszhxm0001w1zra5geymcb` — YouTube 「일본어 공부, 진작 이렇게 할걸… 10년 차 통역사가 직접 보여주는 일본어 독학법」(바로일본어 수지센세, 약 27분 40초, 자동 자막). 외부에서는 로그인 뒤라 열리지 않아 **사용자 허락(2026-10-21)으로 TheThinker 에서 그 1건을 읽기 전용(SELECT)으로 읽었다**. 자막 원문은 이 프로젝트에 저장하지 않고 분석만 남긴다. TheThinker 가 만든 요약과 자막 원문을 대조해 용어를 확인했다(조각 이름·슬래시·밑줄 설명 — 일치).
- **강의의 방법(요지)**: 문법을 처음부터 완벽히 하려 하지 않고 문장을 **조각**으로 나눠 이해한다 — **이름 조각(명사)·액션 조각(동사)·느낌 조각(형용사)·꾸임 조각(부사)** + 조사는 **연결 조각**. 순서: ① 하루 일을 한국어 짧은 문장 5개로 쓴다 → ② 일본어 문장 + 한국어 발음 + **슬래시(/) 끊어 읽기**를 받는다 → ③ 각 문장을 조각 단위로 **밑줄 + 조각 이름 표기** → ④ 조각을 종류별 목록으로 모은다 → ⑤ 조각을 **바꾸거나 붙여 새 문장**을 만든다 → ⑥ 자연스러운지 교정을 받는다 → ⑦ 조각 하나를 바꿔 문장을 늘려 가는 **퀴즈**(시간 조각 교체·액션 조각 교체·길이 확장)를 반복. 매일 5문장 → 2주에 문장 70개·조각 50개 이상 축적을 목표 수치로 든다.
- **앱에 이미 있는 것과 맞닿는 곳** [확실 — 스키마 확인]: 앱의 `ChunkType` 이 `NAME · ACTION · FEELING · MODIFIER · EXPRESSION` 으로 **강의의 이름·액션·느낌·꾸임 분류와 같다**(단어장 «조각» 필터·유형, IMP-0002·0003·0040~0042). 다만 강의의 **«연결 조각»(조사)** 은 `ChunkType` 에 없다(품사 `PARTICLE` 만 있음) — 조사를 조각으로 보일지는 착수 때 결정.
- **«조각» 단계에 가져올 아이디어(제안 — 사용자 결정 필요, 추측 포함)**:
  1. 앞 단계(이해)의 회화 문장마다 **슬래시 끊어 읽기 보기**와 **조각별 밑줄 + 이름 라벨**(색만으로 구분하지 않고 글자 라벨 병기 — 접근성)을 토글로 보여 준다. 조각을 누르면 그 조각만 재생·뜻 표시(IMP-0012 의 구간·파트 재생과 같은 방향).
  2. **분해는 레슨 생성 때 한 번** 만들어 레슨 내용에 저장하고 보기 때마다 LLM 을 부르지 않는 쪽이 지연·비용 면에서 안전하다(추측). 검증은 결정적으로 — 조각을 이어 붙이면 원문 문장과 같아야 하고 유형은 허용 목록 안이어야 한다.
  3. 모은 조각은 **단어장 «조각» 으로 이어지게** 하되 **AI 는 제안만, 사용자가 채택해야 저장**(앱 원칙).
  4. 강의의 «조각 교체·문장 확장 퀴즈» 는 **응용 단계**(말하기·마이크 기본 + 한글 번역 — 보완 1)와 자연스럽게 이어진다.
- **강의가 알려 주지 않는 것·주의**: 활용형을 조각 하나로 볼지(食べました) 어간+어미로 나눌지·조각 크기 기준·N3 이상에서의 효과 근거(강의에도 정량 자료 없음, 요약의 «missing»)·AI 번역·교정만으로는 실제 통용 표현인지 100% 확신할 수 없다는 한계(강의도 인정) — 조각 분해도 LLM 산출이므로 «자동 분해는 참고용» 고지와 오류 신고·교정 경로가 필요할 수 있다(추측).
