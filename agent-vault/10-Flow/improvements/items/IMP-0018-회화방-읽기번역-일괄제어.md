## 현상

회화방에서 확인해보니 읽기, 번역에 대해서 각 글자영역만 표기해주는게 아니라

(현재: 읽기·번역을 말풍선마다 따로 연다. 사용자가 말한 내용(내 말풍선)에는 읽기·번역이 없다 — 2026-10-03 '쇼핑' 대화의 USER 메시지 `reading`·`translation` 모두 비어 있음)

## 기대하는 모습

상위의 AI프로필 영역 아래에 한번에 제어할 수 있도록 해줘. 그리고 사용자가 말한 내용도 동일하게 읽기와 번역이 가능하도록 해줘

## 근거

사용자 F6 점검(앱 1.0.2, 2026-10-03). 스크린샷 없음.

## 분류 메모 (착수 때 Leader)
