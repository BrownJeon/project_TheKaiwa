## 현상

회화시 AI가 답변한 내용중에 문법이 이상한 것이 있었어. 내가 '비밀봉투 부탁드립니다.'라고 하니 응답으로 '비닐봉투를 드려드리겠습니다.'라고 했는데

## 기대하는 모습

정상적인 표현이라면 '비닐봉투를 드리겠습니다'이기에 문법에 대한 체크 한번해줘.

## 근거

실측(2026-10-03, TALK 대화 '쇼핑', 주제·상황 없음, traceId `t_rApoXn51DLgsUlR4OfBD`):
- USER(실시간 인식) `ビニール袋お願いします`
- ASSISTANT 일본어 `かしこまりました。ビニール袋をお付けします。ほかにご不明な点はございますか？` — 점원이 실제로 쓰는 표현, **일본어는 문제 없음**
- ASSISTANT 번역 줄 `알겠습니다. 비닐봉투를 드려드리겠습니다. 다른 궁금한 점이 있으신가요?` — **한국어 번역의 이중 높임(드려 + 드리다) 비문**. 자연스러운 번역은 "비닐봉투 넣어 드리겠습니다".

## 분류 메모 (착수 때 Leader)

- 원인 층 = A1 talk 프롬프트가 내는 `translation`(한국어) 품질. prompt-engineer: 번역 규칙(자연스러운 한국어 존댓말·이중 높임 금지·직역체 피하기, 예 お付けします → "넣어 드리겠습니다") + 회귀 픽스처. A1 ≤3,000자 예산 확인. 화면 변경 없음 → light 트랙 후보.
