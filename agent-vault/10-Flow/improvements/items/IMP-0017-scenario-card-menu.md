## 현상

다른 앱을 사용하다보니까 'amiko'라는 앱의 좋은 메뉴가 있어서 지금의 회화 메뉴의 채팅 항목을 바꿔보려고해.

## 기대하는 모습

'시나리오'라는 항목으로 추가해주고 장소와 상황에 대한 목록들이 있는 카드가 있고 카드를 선택하면 기본 시나리오가 존재해서 이것에 맞춰서 AI가 회화에 대한 스크립트를 생성하는 것으로 보여지는 것같아.
앱을 너가 직접 열어서 볼수는 없으니 내가 추가로 앱에서 캡쳐한 화면을 올려줄께 참고해서 화면을 구성해서 추가할 수 있는 작업 진행하자

## 근거

'amiko' 앱 캡처 9장 — 모두 **시나리오를 고른 뒤의 대화방**이다. 장소·상황 **카드 목록 화면은 아직 없다**(사용자가 추가로 올리겠다고 함).

- ![[IMP-0017-1.jpg]] 대화방 첫 화면. 위쪽 ← 상대 이름(Marcus)·`L3`·`정중한` 칩·번역 아이콘·귀 아이콘·⋮ 메뉴. 화면 전체가 상황 배경 일러스트(도쿄 사무실, 상사 캐릭터). "배경 스토리" 카드(📖 "도쿄의 회사에 겨우 한 달밖에…"), 상대 첫 말풍선(후리가나 + ▶ 재생 + 한국어 번역 줄, 접기 ⌃). 아래에 "탭하여 답장 연습 ⌄", 입력창 "어떤 언어로든 입력…", ✨·⏩ 아이콘, [말해보기].
- ![[IMP-0017-2.jpg]] 대화 진행. 상대 말풍선(왼쪽, 어두움)과 내 말풍선(오른쪽, 밝은 반투명)이 배경 위에 겹쳐 쌓임. 긴 문장을 재생하는 동안 말풍선 위에 재생 컨트롤(속도·재생·일시정지·반복)이 뜸.
- ![[IMP-0017-3.jpg]] "탭하여 답장 연습" 패널 — **선택** 탭: 내 차례 문장의 빈칸 채우기 + 한국어 번역(정답 부분만 강조) + 보기 A/B/C 3개. 패널 위에 [선택][말해보기][따라 읽기] 탭·✕, [따라 읽기] 체크박스·[바꾸기].
- ![[IMP-0017-4.jpg]] 같은 패널 — **말해보기** 탭: "다음을 일본어로 말해보세요" + 한국어 문장, 입력창·[말해보기] 마이크, [힌트]·[정답 보기]. 오른쪽에 세로 볼륨(속도) 막대. 맨 위에 배경 스토리 카드가 다시 보임.
- ![[IMP-0017-5.jpg]] 같은 패널 — **따라 읽기** 탭: "아래 일본어 문장을 읽어보세요" + 일본어(후리가나)·한국어, [듣기][따라 읽기][보내기].
- ![[IMP-0017-6.jpg]] 내가 답한 말풍선이 붙고 상대가 입력 중(`…`). 답장 패널은 닫힌 상태.
- ![[IMP-0017-7.jpg]] **듣기 모드**(귀 아이콘 켜짐): 말풍선 글자가 흐리게 가려지고 [듣고 나서 보기] 버튼. 재생(▶)만 가능.
- ![[IMP-0017-8.jpg]] 번역 줄을 접은 상태(말풍선 모서리 ⌄)로 대화가 이어짐. 상대의 다음 말("今日中と言われても、もう夕方ですよ…")이 나와 있고 아래에 다시 "탭하여 답장 연습".
- ![[IMP-0017-9.jpg]] ⋮ 설정 메뉴: **[레슨 모드 | 캐주얼 채팅]** 전환, 자동 음성 재생(양쪽 모두/상대방만), 이중언어 재생, 음성 속도(1.1x), 핸즈프리 듣기("당신 대신 답장하고 전체 대화를 재생해요 — 듣기만 하세요"), 즉시 피드백(문법과 자연스러움/문법만), 재시작, 언어 변경, 일본어 발음 표기(히라가나/로마자/안 함), 배경 스토리.

## Leader 분류 (2026-09-30 재확인)

- **판정: 유효 → `triaged`.** 현재 회화 탭에는 시나리오 화면이 없다(`src/components/chat/StudyAiHome.tsx`·`NewChatSheet.tsx` 의 "채팅" 목록·새 대화 시트뿐). 이미 해결된 항목이 아니다.
- **[[task-010d-scenario-roleplay]] 와 범위 겹침 — 합치는 것을 권고.** 010d 는 상황 10개(주제 5×상황 2)·역할·목표·핵심 표현·종료 판정·결과 카드의 **서버·데이터·프롬프트**를 이미 설계했고 화면 데모 v1 이 사용자 검토 대기다. 이 항목이 더하는 것은 (a) 회화 탭 진입점을 '시나리오' 카드 목록으로 바꾸기, (b) amiko 식 **대화방 UX**(상황 배경·"배경 스토리" 카드·"탭하여 답장 연습" 3모드[선택/말해보기/따라 읽기]·듣기 모드·⋮ 설정 메뉴)다. 010d 서버를 그대로 쓰고 화면만 새 데모(v2)로 다시 그리는 편이 낫다.
- **캡처 9장은 대화방 화면뿐.** 장소·상황 **카드 목록 화면은 아직 없다** — 사용자가 추가로 올리기로 했으므로 착수 전에 받아야 한다(받기 전에는 데모 설계 금지).
- **저작권·범위 원칙**: amiko 는 **구성·흐름의 참고**로만 쓴다. 일러스트·캐릭터·문구·상표는 복제하지 않고 이 앱의 토큰·문구·엔진명 비노출 원칙(`brand.ts`)으로 다시 그린다.
- **사용자 결정 필요(착수 때)**: ① 기존 '채팅'을 **대체**할지 **'시나리오'를 추가**할지(요청 글은 "추가"이지만 제목은 "변경") — 채팅 교정 기능(task-006)은 어디에 두는가 ② 3모드 답장 연습·듣기 모드·설정 메뉴 중 **이번 범위에 넣을 것**(전부 넣으면 010d 보다 큰 별도 에픽) ③ 010d 데모 v1 을 v2 로 대체할지.
- **의존**: 010d 스키마(`Scenario`·`Chat.scenarioId`)는 사용자 DB 승인 대기와 같은 줄에 있다.
