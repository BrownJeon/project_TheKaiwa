## 현상

> 단어에서 한글표기도 추가해줘

(사용자 원문 — 2026-10-21, 스크린샷: 「자기소개」 새 단어 5장 · 챌린지 안내가 붙은 오늘의 단어 화면, 2번 카드 `来ました` 를 틀린 보기로 답한 뒤 «지난 카드 보는 중». 카드에 후리가나 루비·뜻·예문은 있고 **표제어·예문의 한글 발음 줄이 없다**.)

## 기대하는 모습

단어 카드에서도 한글 표기(`[키마시타]`)가 보인다. 이 사용자의 앱 한글 설정은 켜져 있다(`showHangul: true`, 2026-10-21 읽기 전용 조회).

## 근거

- **원인 [확실 — 재현]**: 한글 표기 기능은 이미 있다(`VocabCardFace` 뒷면 표제어·예문 `HangulLine`). 그런데 «카드에 자리가 없을 때만 한글 줄을 뺀다(C2-A, 번역 우선 — 예문 줄 → 표제어 줄)» 규칙이 있고, 주제 세트·챌린지 화면은 카드 위에 안내 2줄이 더 붙어 카드가 눌린다(사용자 화면의 카드 ≈ 226 css px, 기본 세트 ≈ 339px). QA 계정으로 같은 화면에서 화면 높이만 줄이면 재현: 카드 높이 313 → 261 → 224 → 187px 에서 한글 줄 2개 → 2 → 1 → 0개(`task-082` 이력서 «사실»).
- 분석 API(`POST /api/v1/text/annotate`)는 `来ました`·«去年 日本に来ました。» 모두 정상(발음 キ·マシ·タ) — 데이터 문제 아님.
