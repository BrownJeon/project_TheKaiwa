## 현상

회화 중에 사용자가 말하려고할때 잘 생각나지 않는 단어나 문장의 도움을 받기 위해서 한국어로 질의하면 적절한 일본어를 알려줄 수 있는 도우미가 있었으면 좋겠어.

## 기대하는 모습

이건 기존 마이크로 말하는 버튼 외에 우측에 바로 배치해서 별도로 도움을 받는 방식으로 해줬으면 좋겠어

## 분류 메모 (착수 때 Leader)

- (사실만, Leader 가 등록 시 확인한 것 — 해결책이 아니다) 같은 화면에는 이미 비슷한 도움이 있다: 스크린샷으로 본 역할극 방에는 마이크 위에 「대답 연습 — 무엇을 말할지 막히면 눌러요」 줄이 있다(`src/components/scenario/PracticeDock.tsx`, AI 가 답 예시를 주는 기능으로 보임 — 일반 회화방에도 있는지는 미확인). 이번 요청은 **사용자가 한국어로 직접 질의**하고 마이크 버튼 **오른쪽에 별도 버튼**이라는 점이 다르다. 착수 때 중복·통합 여부를 판단한다.
- Phase 3 의 「무엇이든 물어보세요」(5번째 탭, 일본어 표현·문법 질문)와 기능이 겹칠 수 있다 — 같은 AI 호출 경로·계약을 쓸지 착수 때 판단한다.
- 새 AI 호출 지점이 생기면 프롬프트 설계(prompt-engineer)와 5초 예산·교정 원칙(AI 는 제안만, 저장은 채택 시에만)을 같이 본다.

## Leader 재확인 (2026-10-11, `/개선작업 착수` 1단계 — 읽기 전용)

- **판정: 유효 → `triaged`.** 이미 해결된 항목이 아니다.
- 확인한 사실(코드):
  - 「대답 연습」(`PracticeDock`)은 **역할극 방 전용**이다. `useRolePlay.ts:150` `target = active && !ended ? practiceTargetOf(messages) : null` — 일반 회화방(`rp.active` 거짓)에서는 `practiceShown` 이 거짓이라 아무것도 그리지 않는다.
  - 대답 연습은 **마지막 선생님 말에 대한 답 예시**(고르기·말하기·따라 하기)를 주는 기능이다. 사용자가 **한국어로 직접 질의**하는 입구는 없다. `PracticeDock` 의 판은 마이크·보내기를 두지 않고 [입력창에 넣기]까지만 한다(D-8) — 이 패턴은 이 요청의 결과 전달 방식 후보로 참고할 수 있다.
  - 「무엇이든 물어보세요」(`/ask`)는 아직 `ComingSoon`(Phase 3) 뿐이다(`src/app/(app)/ask/page.tsx`). 호출 경로·계약이 아직 없어서 겹침 판단은 착수 때 새로 해야 한다.
- 규모 의견(Leader): 회화방 입력 영역 구조 변경 + **새 AI 호출 지점** → 데모 게이트(full 또는 delta) 필요, prompt-engineer 계약 설계 필요, 실시간 회화 경로(푸시투토크→턴→TTS)에 동기로 넣지 않는 별도 호출. light 트랙 대상 아님(신규 화면 요소·신규 AI 계약).
- 사용자 결정이 필요한 것(착수 시 Leader → 사용자): ① 범위 = 일반 회화방만 / 역할극 방도(역할극엔 대답 연습이 이미 있다) ② 결과 모양 = 일본어 표현 + 읽기 + 뜻 + 재생 + [입력창에 넣기](AI 는 제안만, 단어장 저장은 사용자가 채택할 때만) ③ `/ask` 와 같은 호출 경로를 쓸지 ④ 마이크 오른쪽 배치가 입력 바 폭(360px)에서 가능한지는 designer 데모에서 확인.
