## 현상

일본어 표기 아래에 한국어 발음(한글)이 표기되지 않음.

## 기대하는 모습

일본어 표기에 대하여 아래에 작은 글씨로 한국어 발음도 함께 표기해줘. 지금 전체적으로 모든 일본어 표기 아래에 한글로 표기해주는 것 기본적으로 추가해줘

예: これはいくらですか？
　　코레와 이쿠라데스까?

## 근거

## 분류 메모 (착수 때 Leader)

- 재확인: 유효(기능 없음). 코드에 한글 발음 표기 개념이 전혀 없다 — 읽기(후리가나)는 히라가나 `reading`·`replyReading` 뿐이고, LLM 계약은 오히려 일본어 필드에 한글이 섞이면 위반으로 거절한다(`structuredResponse/checks.ts` hasHangul). `docs/screens.md` §1-3 도 히라가나 읽기만 규정.
- 구현 갈래: (a) 히라가나 읽기 → 한글 표기를 **규칙 변환기**(가나→한글, 장음·촉음·ん 규칙)로 클라이언트/서버에서 생성 — 무료·결정적·전 화면 공통, 한자는 이미 있는 읽기(reading)를 거쳐야 함 (b) LLM 이 한글 발음 필드를 새로 내게 함 — 스키마·프롬프트·저장 데이터 전부 바뀌고 응답이 길어져 5초 예산에 불리. Leader 의견은 (a). 표시 대상은 단어 상세·카드·회화방 말풍선·오늘의 회화 전 단계·채팅 등 "일본어가 나오는 모든 곳"이라 화면 수가 많다.
- 영향 파일: 신규 공용 변환 유틸(`src/components/common/` 또는 `learning`), 일본어를 그리는 컴포넌트 전반(`vocab/*`·`talk/*`·`lesson/*`·`chat/*`), `docs/screens.md` §1-3, 설정(표시 on/off — IMP-0015 토글과 통합). 규모 L. Leader 의견: 사용자 질문 Q7(한글 표기는 읽기가 있는 곳 전부 vs 예시처럼 문장 단위 · 기본 on/off · 토글 위치). IMP-0015 와 같은 task 로 묶는다(디자이너 full 데모 대상).
