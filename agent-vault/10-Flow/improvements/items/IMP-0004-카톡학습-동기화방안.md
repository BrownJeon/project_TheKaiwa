## 현상

수지센세가 주기적으로 카톡에 올려주는 학습내용이 앱과 연결되어 있지 않음.

## 기대하는 모습

수지센세가 주기적으로 카톡에 올려주는 학습내용에 대해서 앱에서 동기화할 수있는 방안

## 근거

## 분류 메모 (착수 때 Leader)

- 사실 조사(질문 답변): 카카오톡에는 다른 앱이 대화를 읽는 공개 API가 없다. 앱에 이미 있는 것은 **오늘의 회화 '붙여넣기'**(`/study/today/talk/new/paste`, `LessonPasteScreen.tsx` — 일본어 텍스트 50~2000자를 붙여넣으면 서버가 일본어 비율을 판정하고 수업 생성)뿐. 안드로이드 공유 수신(Share Target)은 없다 — `AndroidManifest.xml` 의 intent-filter 는 LAUNCHER·`thekaiwa://auth/callback` 둘뿐.
- 방안 후보: (a) 현행 수동 붙여넣기 유지(0원, 이미 됨) (b) **안드로이드 공유하기 대상 등록**(카톡 메시지 길게 눌러 공유 → Lingofy 선택 → 붙여넣기 화면에 자동 채움) — 네이티브(Manifest·플러그인) 변경이라 APK 재빌드·재설치 필요 (c) 카톡 '대화 내보내기' txt 업로드·파싱 (d) 알림 접근 권한으로 자동 수집 — 개인정보·권한 부담이 커서 비권장.
- 영향 파일(b 채택 시): `android/**`·`plugins/**` 또는 Capacitor 공유 플러그인, `LessonPasteScreen.tsx`. 규모 L(네이티브 포함) / (a)는 0. Leader 의견: 기능 task 로 넣기 전에 사용자가 방안을 고르는 것이 먼저 — Q3. 화면은 "오늘의 회화"에 속한다.

## 착수 결정 (사용자 답변, 2026-09-30)

- Q3 "우선은 카톡 연동을 수동 붙혀넣기로 해주고 추후 플러그인을 통해서 자동으로 크롤링 하도록 작업해줘" — **1단계 = 현행 수동 붙여넣기 유지(추가 작업 없음). 2단계 자동 수집 플러그인은 별도 task 로, 착수 전에 방식 검토와 보안·신규도입(/신규도입) 검토가 먼저 필요**(카카오톡은 공개 API 가 없다).

## 사용자 결정 (2026-10-03) — 2단계

- **2단계 = 안드로이드 '공유하기' 대상 등록(방안 b)** 채택(AskUserQuestion, 권고안). 카톡 메시지를 길게 눌러 공유 → Lingofy Japanese 선택 → 오늘의 회화 붙여넣기 화면(`LessonPasteScreen`)에 본문 자동 채움. 자동 수집(알림 접근 등, 방안 d)은 하지 않는다 — 사용자가 고른 글만 들어온다.
- 네이티브 변경(AndroidManifest `ACTION_SEND` `text/plain` intent-filter + 수신 처리) → **APK 재빌드·versionCode 증가·업데이트 안내**(deployer). 외부 공유 수신 플러그인 패키지를 들이면 착수 전 `/신규도입`, 기존 커스텀 플러그인(Kotlin)에 넣으면 불필요 — 착수 때 Leader·judge 판단. 데모 수준은 judge 판정.
- task 생성은 task-026 뒤 순서에서 Leader 가 개선 task 로 묶는다(그때 `planned`).
