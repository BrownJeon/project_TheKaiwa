## 현상

현재는 객관식과 카드 방식을 선택하는 구조로 되어 있음.

## 기대하는 모습

방식을 객관식과 카드로 선택하는 것이 아니라 기본은 카드로 생성해주고 카드를 탭하면 객관식으로 고를수있도록 하고 '뜻 보기'로 나온 카드에서 단어와 예제 문장의 발음을 들을수있도록 재생버튼을 만들어줘

## 분류 메모 (착수 때 Leader)

- 재확인: 유효. `TodayWordsCard.tsx` 에 `Segmented` 로 방식 선택(4지선다 CHOICE / 뒤집기 카드 FLIP, `MODE_OPTIONS`) 노출. 덱 화면 `VocabDeck`·`VocabCardFace` 에 재생 버튼 없음(screens §5 E9 "소리 버튼 없음").
- 요구를 나누면: ① 방식 선택 제거·카드 기본 ② 카드 탭 → 객관식 전환 ③ '뜻 보기' 면에서 단어·예문 재생. ③ 은 범용 TTS 로 화면만 추가(S). ①② 는 세트 저장 모델(`VocabSession.mode`, attempt 채점 — CHOICE 는 서버 채점, FLIP 은 자기 표시)에 영향: 카드에서 객관식으로 넘어간 결과를 어떻게 기록·통계화할지 결정 필요(현재 통계·`StatsSnapshot` 은 모드 구분).
- 영향 파일: `TodayWordsCard.tsx`·`VocabSessionScreen`·`VocabDeck`·`VocabCardFace`·`useVocabDeck`·`deck.ts`, API #47~#54 세트 생성 body(mode), `docs/screens.md` §5. 규모 M~L(채점 모델 결정에 좌우). Leader 의견: task-008 화면 구조 변경이므로 designer full 데모 필요. Q9: 카드→객관식 시 정답 기록을 CHOICE 로 통일해도 되는지. 재생 버튼은 IMP-0001 과 묶는다.
