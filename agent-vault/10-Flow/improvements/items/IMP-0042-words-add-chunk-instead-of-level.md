## 현상

단어 추가 시트의 직접 입력 폼에는 「수준」(JLPT 단계) 항목이 있고 조각을 고르는 칸은 없다.

## 기대하는 모습

> 6. 단어장 추가시 직접 입력의 경우 '수준' 항목은 제거해주고 대신에 조각에 대한 선택을 할 수 있는 항목으로 교체해줘. 이것은 이미 배포되어 있는 단어들도 포함된 내용으로, 배포된 단어들도 조각항목으로 표기될 수 있도록 해줘

(사용자 요청, 2026-10-14)

## 근거

- `WordEntry.jlpt` 는 DB 에 남고(오늘의 단어 단계 가중 등이 읽는다) 화면의 입력 칸만 없앤다. 직접 입력 단어의 수준은 비워 둔다 — 비어 있을 때 가중·표시가 어떻게 되는지 구현 때 확인.
- 「배포된 단어들도 조각항목으로 표기」 = 기본 팩 단어 행·상세에도 조각 뱃지가 보이게(현재 조각 뱃지는 task-023 에 있음 — 어느 화면에서 빠져 있는지 확인). IMP-0041 의 새 유형이 정해지면 그 유형 라벨까지 포함.
