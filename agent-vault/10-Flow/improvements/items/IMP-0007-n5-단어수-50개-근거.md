## 현상

N5에 학습해야할 단어가 50개가 전부인가? 50개로 잡아놓은 이유가 뭐야?

## 기대하는 모습

(질문 — 착수 시 현재 seed 데이터의 N5 단어 수 산정 근거를 확인해 답변, 필요 시 보강)

## 근거

## 분류 메모 (착수 때 Leader)

- 사실 조사(질문 답변): 50개는 **설계 시 정한 초기 시드 수량**이다. `docs/design/domain-model.md` §7 시드 3번("OWNER 계정에 N5 단어 50개, chunkType 채움")에서 정해졌고 `prisma/seed-data/words-n5.json` 이 단일 출처(git 첫 등장 커밋 e22fd7e, task-002, 2026-09-26). 문서 어디에도 50 이라는 숫자의 산정 근거(JLPT 출제 범위·빈도 등)는 적혀 있지 않다 — 즉 "앱이 시작할 수 있는 최소한의 팩"이며 **N5 어휘 전체가 아니다**(일반적으로 N5 어휘는 수백~약 800개로 알려져 있으나 이 저장소에는 공식 목록 근거가 없다). 구성: 이름 조각 16·액션 15·느낌 9·꾸밈 8·미지정 2. 화면 문구도 "기본 단어 50개(N5)"로 고정(`screens.md` §4·§5, 시드 팩 API `pack:'N5'`).
- 영향 파일(보강 시): `prisma/seed-data/words-n5.json`, `seedPack.ts`(팩 이름·수량 문구), 화면 문구 다수. 규모 S(데이터만) ~ M(팩 N5-2 분할·문구). Leader 의견: 답변 완료. 추가 어휘가 필요한지·어느 소스(직접 작성/공개 목록)를 쓸지 사용자 결정 후 별도 task — Q6. 결정이 없으면 dropped(질문 종결).

## 착수 결정 (사용자 답변, 2026-09-30)

- Q6 단어 출처·난이도별 단어 존재 여부를 사용자가 질문함 — 답변을 드렸고 **단어 출처 방식(공개 목록 + Claude 보강 / 전부 AI 생성 등) 결정 대기.** 결정이 없으면 dropped 처리 검토.
