## 현상

JLPT 5단계 기본 단어(초보자~최상급)를 넣으면 오늘의 단어 세트가 보관하지 않은 단어 전체에서 **풀 비중대로** 뽑힌다. QA 실측(전 단계 7,755개 보유 계정, 40세트·400장): 최상급 41.5% · 고급 22.5% · 중급 20.8% · 초급 10.3% · 초보자 5.0%. 초보자가 상위 단계를 넣을수록 오늘의 단어가 어려워진다. 세트 생성 가중(`setGenerator.ts` `weightOf`)이 단어의 단계를 보지 않는다.

## 기대하는 모습

- 내 수준(`Profile.level`)과 목표 수준(`goalLevel`) 중 **높은 쪽을 천장**으로, 천장 이하 단어는 지금처럼 같은 가중, 천장 위만 줄인다.
- 사용자 결정(2026-10-11, 「중간」): 천장 위 1단계 ×0.3 · 2단계 ×0.05 · 3단계 이상 ×0(나오지 않음). 단계 정보가 없는 내 단어(`jlpt` 비어 있음)는 그대로(×1).
- 후보가 모자라 세트를 채울 수 없을 때(예: 내 단어가 전부 천장보다 어려운 단계)는 가중 0 단어도 **마지막에 채운다**(세트가 비지 않게).

## 근거

- 사용자 선택: 「중간」·「포함: 천장 = 지금·목표 중 높은 쪽」(AskUserQuestion, 2026-10-11).
- 후보 규칙별 분포 계산(초보자·전 단계 보유): 현재 8.7/8.1/21.3/22.8/39.1% → 중간 71.4/19.9/8.7/0/0%. 초보자+초급 팩만 보유하면 규칙과 무관하게 51.8/48.2%로 변하지 않는다(상위 단계를 더 넣었을 때만 작동).

## 분류 메모 (착수 때 Leader)

- 서버 모듈 변경만(`vocab/setGenerator.ts`·`sessions.ts`·`topicSet.ts`+시험, 설계서 §7-2 공식 갱신). 화면·스키마·네이티브 변경 없음 → 웹 배포만. judge 접수는 `origin: improvement` 로 light 트랙을 시도한다.
