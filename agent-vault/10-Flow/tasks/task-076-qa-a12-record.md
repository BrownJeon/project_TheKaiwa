## 4. 관찰 (결론 아님 — 해석은 Leader)
1. **통과율**: 한 단계 차이 두 경우 모두 대조군과 구별되지 않고, 두 단계 차이만 폴백으로 무너진다. 이번 표본에서 중간 지점(일부만 통과하는 SHORT)은 N2 의 이전 시도 1회(2장) 말고는 나오지 않았다.
2. **표본 크기 주의 [확실]**: 변형은 N3·N5·N2 각 **1세트씩**, 대조는 이번 3세트 + 이전 1세트(주제 다름). 한 단계 차이 «10/10» 은 n=1 이라 «대조와 같다» 가 아니라 «이번에는 모두 통과» 로만 읽을 수 있다. 반대로 N2 는 서로 다른 주제 2개(주말 계획·회사 점심)에서 3회 연속 0·2·0장이라 우연으로 보기 어렵다. 계정·주제·시각이 다르므로(대조는 QA3, 변형은 QA1; 주제는 교차 일치) 계정 효과는 완전히 배제하지 못함.
3. **기계적 원인 후보 [가능성 높음, API 로는 확인 불가]**: 코드상 새 단어 통과 조건 중 하나가 «모델이 단 jlpt 가 수준 창(챌린지 수준 ±1) 안» 이다(`topicWordsLevelWindow`, `JLPT_WINDOW` 탈락). 주제 수준 N4 는 N3 창(N4·N3·N2)과 N5 창(N5·N4)에는 들어가지만 N2 창(N3·N2·N1)에는 들어가지 않는다 → 한 단계 차이는 주제 수준 단어가 창 안에 남아 그대로 통과하고, 두 단계 차이는 N4 급 단어가 창 밖이라 탈락할 가능성. 다만 응답에 탈락 사유가 없어(`generation.reason` 은 INVALID/SHORT 집계뿐) 실제 탈락이 `JLPT_WINDOW` 때문인지 다른 검사(표기·읽기·중복) 때문인지는 이번 측정으로 확인하지 못했다.
4. **한 단계 차이에서 단어 수준이 실제로 움직였는가는 불분명 [추측]**: API 응답에 단어별 `jlpt`·수준 필드가 **없어** 직접 집계 불가(A12 응답 안에서만 쓰고 카드에 저장하지 않음).
