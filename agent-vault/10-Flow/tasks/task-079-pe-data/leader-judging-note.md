# Leader 눈가림 판정 메모 (task-079, 2026-10-20)

- 판정자: Leader(AI) 한 명. 한국어 판정이라 사용자 표본 확인 권고. 판정은 `sealed/key.json` 을 열기 **전**에 끝냈고, 열쇠는 판정 후에만 열었다(arm 별 불량 목록 표를 만들기 위해).
- 기준(고정): 맞음 = 한국에서 그 뜻으로 실제 쓰는 자연스러운 말 / 어색 = 통하지만 한국어로 잘 안 쓰거나 부자연스러운 말(한자음 어색 읽기·원문에 없는 뜻 덧붙임·문장 표현을 설명 문구로 바꿈·**같은 낱말 반복** 포함) / 틀림 = 다른 뜻. 단어 안의 **어느 뜻 하나라도** 어색/틀림이면 불량 단어.
- 입력 표에는 구(句) 표현(예: 「辛いですか」)이 섞여 있었다 — 뜻이 원문 문장과 같은 형식인지(문장은 문장으로) 도 보았다.
- 주의: 이 기준은 task-079 이력서 앞부분의 저장 카드 12%(7/57) 판정보다 **엄격**하다(그때는 명백한 오류만 골랐다). 그래서 v3 불량이 27% 로 나온다 — 이력서의 «절대 6% 이하» 합격선은 느슨한 기준의 12% 를 절반으로 잡은 것이라, 엄격한 기준과 맞지 않았다(사전 등록 실수, 사후에 선을 바꾸지 않고 사용자 결정으로 넘긴다).
- 결과(`leader-score.log`): v3 불량 단어 27/100(뜻 단위 19.3%), v4 13/100(11.8%) → 상대 기준(≤ 절반 13.5%) 통과, 절대 6% 미달 → **gate (a) 불합격**. 피셔 정확검정 p=0.021(같은 구간 비교), v4 의 같은 뜻 반복 3건(코드로 접을 수 있음)을 빼면 10/100 (p=0.003).
- 한계: ① 단어당 뜻 개수가 1.50→1.19 로 줄어 «불량 단어가 줄어든 것»의 일부는 보조 뜻 자체가 줄어든 효과 ② 판정자 단독 ③ 표본 200단어.
