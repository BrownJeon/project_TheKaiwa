## 「결정 필요」 항목 (데모 패널과 같은 번호, 굵은 것이 권고)
1. **D1 들어가는 길** — **A 앱바 아래 분절** / B 앱바 글자 버튼 「교정 모음」 / C 검색 위 안내 줄. 이유: 가장 잘 보이고 돌아오기가 같은 자리, 높이 비용 +52px 는 정적 요소라 자리표시 상수 영향 없음.
2. **D2 카드 모양** — A 교정 카드 그대로 / B 접힌 줄 / **C 요약 카드(윗부분 전체가 펼침 버튼, ✕/✓ 표시)**. 이유: 「무엇을 틀렸나 → 어떻게 고치나」 두 문장이 늘 보이는 안 중 가장 낮음(A 대비 −40%).
3. **D3 필터** — **A 칩 두 줄(유형 개수 표시)** / B [필터] 버튼+시트. 이유: 단어장과 같은 부품·한 번 누름·개수가 보임. 밀도를 더 원하면 B(−50px).
4. **D4 더 보기** — **A 버튼** / B 끝에 닿으면 자동. 이유: 단어장과 같음, 화면 읽기에서 갑자기 늘지 않음.
5. **D5 원래 대화에서 ←** — **A 「교정 모음으로」** / B 그대로(회화 목록·대화). 이유: ← 와 휴대폰 뒤로가 같은 곳. [확실] `BackBar` 와 `TalkRoomHeader` 둘 다 `usePlanReturn` 을 쓰므로 공용 변경은 그 훅 한 곳(계획표 돌아오기 방식을 교정 모음에도).
6. **D6 단어 보기** — **A 이 화면 위 단어 상세 시트(기존 WordDetailSheet)** / B `/drawer/words?word=` 이동. 이유: 닫으면 같은 자리·같은 조건. 시트에서 단어를 지우면 카드의 단어 링크를 거두려고 목록을 다시 읽는다.
7. **D7 번역** — **A 히라가나·한글 두 스위치만** / B 고친 문장 아래 번역 줄. [확실] Correction 에 번역 칸이 없고 지금 교정 카드도 번역을 그리지 않는다 → B 는 새 데이터(저장 칸 또는 화면별 번역 요청)라 계약·프롬프트 변경, Leader 결정·이번 범위 밖. Leader 지시문의 「번역 스위치를 따른다」와 다르므로 확인 필요.
8. **D8 검색 대상** — A 일본어 두 문장만(계약 §2-17 그대로) / **B 설명까지(Leader 초안)**. 이유: 한국어로 기억하는 말(예: 존댓말)로 찾을 수 있음 — A 면 0건(데모 C 탭). B 를 고르면 계약 문구 갱신(Leader).
