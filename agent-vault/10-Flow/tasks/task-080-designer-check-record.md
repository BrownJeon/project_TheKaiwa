### 권고
1. **② 를 권고한다 — 사용자 확인 필요**(승인 데모와 배치가 달라짐 → 데모 v5 delta 또는 사용자 한 줄 승인). 이유: 효과가 L2 결정·백필 시점·사용자 수준과 무관하고, 안내 문장의 뜻(«단계는 기록이 모이는 대로 보여요»)이 단계가 그려지는 자리와 맞는다. **L2 결정과 같이 묻기를 권한다** — L2 가 B·C 면 #1 도 안내가 계속 떠서 ② 의 효과가 커지고, A 면 ② 의 혜택은 새·적은 기록 계정에 한정된다.
2. 사용자 결정 전에는 **⓪ 으로 내보내도 된다**(사양 36-13 대로, 알려진 한계 문장만 위 «백필 전·후» 로 고쳐 적기).
3. **① 은 하지 않는다** — 백필 뒤 #1 이 오히려 −67px 로 뒤집힌다.
4. 같은 수정에 P2-4(읽기 줄 값 `whitespace-nowrap`)를 묶으면 좋다(사양 글자·구조 변경 없음 — 사용자 확인 불필요, Leader 판단).
