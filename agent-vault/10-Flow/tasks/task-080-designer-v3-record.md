## 2. 단위·뜻 설명 판단 (Leader 가 확인하라고 한 것)

- **«단어 17세트»**: 어색하지 않다고 봄 → `unit '세트'` 그대로. 단어 세트 정답률 문장(495행, 분석 탭)과는 다른 맥락이라 건드리지 않음.
- **«대화 14번»**: 문법은 자연스럽지만 **뜻이 바뀐다.** 이 숫자는 `talkTurns + chatTurns`(주고받은 말 수, 합성값 주당 14~61)인데 «대화 61번»만 보면 «대화를 61번 했다»(세션 수)로 읽힌다. v2 의 «대화 말 수»가 하던 구분을 이름이 잃었다. → 최소 조정으로 **주석 첫 문장 «대화에서 오간 말의 수예요.»** 만 더했다(단위 «번» 그대로). 기존 문장(«…기록 남기기…고른 대화와 끝낸 역할극만 세요.»)은 그대로.
- **되돌리려면**: 487행 note 의 앞 문장 한 줄만 지우면 v2 문구 그대로다. **다른 선택지(사용자 판단 필요하면 Leader 가 물을 것)**: 단위를 «번» 대신 «마디»/«마디의 말» 같은 말 단위로 바꾸기(예: «대화 14마디») — 이름은 사용자가 정한 «대화» 그대로. 지금은 사용자 지시 범위를 넘지 않으려고 하지 않았다.
- 개발 구현 영향: `label` 상수(코드의 metric 키 → 라벨 상수, 개발 메모 근거표 «evidence{metric, value} 한국어 라벨»)만 이 이름을 따른다. 응답 키(`words.sessions`·`talkTurns + chatTurns` 등)는 그대로.
