## 레이아웃 설계 (page-layout-designer 7항목 — delta 범위)
- **목표**: 방식을 고르지 않고 카드로 바로 풀되, 헷갈리면 같은 카드에서 객관식으로 확인하고, 뜻 보기 면에서 단어·예문을 듣는다. 스와이프는 그대로.
- **주요 위계**: 덱 = 카드(표현) → 카드 아래 듣기 줄(뒷면만) → 힌트 한 줄 → 답하는 버튼(앞면 [뜻 보기]·[객관식] / 보기 4개 / [알았어요]·[몰랐어요]) → 도구 줄. 오늘 홈 = 장수 → [시작하기](방식 줄 없음).
- **영역**: 제스처 영역(카드 면만, 버튼 없음)과 버튼 영역(카드 밖)의 분리는 지금 그대로(§5-0 4). 새 버튼(객관식·듣기)은 모두 카드 밖.
- **컴포넌트**: 기존 `ChoiceList`·`FlipControls`·`DeckToolbar`·`GestureHint`·`VocabCardFace` 재사용 + 앞면 버튼 줄(뜻 보기·객관식) + 듣기 줄(`useWordSound` target `word`·`ex` 재사용, 버튼 모양만 덱용 가로형). 새 라이브러리 없음.
- **상태**: 앞면(보기 닫힘/열림) · 확인 중 · 객관식 정답/오답 · 뜻 보기 면(답 전/기록 중/스스로 답함) · 건너뜀 · 지난 카드 · 보기 없는 세트 · 이전 세트(4지선다/뒤집기) · 소리(대기/불러오는 중/재생/막힘/실패/자막만/너무 자주) · 답 저장 실패 · 결과(섞임).
- **행동**: 주 = 뜻 보기·객관식 고르기·알았어요/몰랐어요·다음 카드. 보조 = 듣기·이전·읽기·표시·건너뛰기·끝내기.
- **반응형**: 360/390/412 모두 덱 스크롤 0. 카드 높이는 340 상한이고, 객관식으로 답한 뒤에만 듣기 줄만큼(데모 실측 −40px) 작아진다.

## 결정 필요 (데모 「결정 필요」 패널과 같은 번호)
- **D0 스와이프의 뜻** — A 지금 그대로(스스로 표시는 [알았어요]·[몰랐어요] 버튼) / B 뜻 보기 면에서만 오른쪽=알았어요·왼쪽=몰랐어요. **권고 A** — 사용자 명시 지시와 맞고, B 는 같은 오른쪽 밀기가 면에 따라 ‘이전’/‘알았어요’로 갈려 잘못 기록될 위험. Q9 숫자는 A 로도 같다.
- **D1 탭 영역·충돌** — A 앞면 아무 곳 탭(10px 미만, 판정 그대로) = 보기 열기/닫기 + 같은 일의 [객관식] 버튼 / B 탭 = 뜻 보기, 객관식은 버튼만 / C 길게 누르기. **권고 A** — 요구 그대로이고 스와이프 판정 무변경, 다시 탭으로 되돌림 가능(고르기 전 기록 없음).
- **D2 답한 뒤 넘어가기** — A 객관식 = 머묾+[다음 카드], 스스로 = 0.4초 뒤 자동 / B 둘 다 자동 / C 둘 다 버튼. **권고 A** — 두 경로 모두 지금 동작 그대로, 객관식은 답한 뒤 뜻·예문·듣기를 볼 시간 필요.
- **D3 재생 버튼** — A 카드 아래 한 줄 [단어 듣기][예문 듣기] / B 카드 안 작은 ▶ / C 한 버튼 이어 재생. **권고 A** — B 는 제스처 영역 예외가 필요(스와이프 불변 충돌), C 는 단어만 다시 듣기 불가. 참고 화면이 한 버튼이면 v2 에서 C.
- **D4 대체 입력** — A 모든 제스처에 화면 버튼 + 키(Space·C·1~4·1/2·←/→·F·R·S), 초점 이동·화면 읽기 알림 / B 카드 탭만 + 숨은 버튼. **권고 A** — §5-0 5 원칙 유지, 보이는 [객관식]이 기능을 알려 줌.
- **D5 결과 구분** — A 합산 + 섞였을 때 한 줄 + 목록 태그 / B 합산만 / C 타일 둘로. **권고 A** — Q9 합산을 첫 숫자로 지키며 「스스로 표시는 채점이 아님」을 한 줄로.
- **D6 이전 세트** — A 시작한 방식 화면 그대로 + 듣기 추가, 이름은 이전 세트만, 다시 풀기는 새 방식 / B 새 화면 규칙(버튼 반쪽) / C 자동 종료. **권고 A** — 혼란 없음·이전 세트용 서버 변경 없음. C 는 기록 변경이라 비권고.
- **D7 버튼 최소안** — A 도구 줄 4칸 그대로 + 객관식 1·듣기 2 / B [건너뛰기] 제거 3칸 / C 참고 화면 뒤 v2. **권고 A**(참고 화면 오면 v2 에서 B·C 재검토) — 앞면은 이미 지금 4지선다보다 2개 적음(8 → 6), 건너뛰기 제거는 기록 경로를 바꿔 범위 초과.
- **D8 설명 문구** — A 그대로 / B 「카드로 뜻을 떠올리고, 헷갈리면 카드를 눌러 객관식으로 골라요.」 **권고 A** — 탭 안내는 덱 카드가 그때그때, 자리표시 재측정 범위 축소, B 는 「틀린 단어일수록 자주」 정보가 빠짐.
