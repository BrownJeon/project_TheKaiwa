무엇을 바꾸나 (delta — 바뀌는 곳만)

어제 배포한 질문 탭(task-066)에서 「지난 질문」으로 대화를 열면 ‹ 뒤로가기 머리에 하단 탭이 없는 별도 화면이 나왔다. 이 화면을 없애고, 지난 대화도 탭 화면 그대로(머리 「질문」 · 「지난 질문」 · ⋯ · 나, 하단 탭, 입력 바) 안에서 대화 내용만 바뀌게 한다. 그리고 질문(대화)마다 제목을 정하는 자리를 눈에 띄는 곳에 두고, 지난 질문 시트를 5개씩 쪽으로 나눈다.

  1. 1머리 「지난 질문」
  2. →
  3. 2시트 5개씩 · ‹ 이전 · 1 / 3 · 다음 ›
  4. →
  5. 3행을 누르면 시트가 닫히고 같은 화면에 그 대화
  6. →
  7. 4머리 「질문」 아래 대화 제목 · 눌러서 제목 바꾸기
  • 지난 대화 전용 화면 — ‹ 질문으로 · 대화 제목 · 「질문 · 선생님」 · 하단 탭 숨김(주소 /ask/〈id〉)
  • 지난 질문 시트의 「이전 질문 더 보기」(아래로 계속 늘어나는 목록)
  • 머리 「질문」 아래에 지금 대화 제목 한 줄(D1) — 누르면 제목 바꾸기(D2)
  • 지난 질문 시트 5개씩 쪽 넘기기(D3) · 각 행 오른쪽 ⋯ → 제목 바꾸기 · 삭제(D2 · D6)
  • 옛 주소 /ask/〈id〉 는 탭 화면으로 보냄(D5) · 지난 질문을 열어도 휴대폰 뒤로가기 기록은 늘지 않음(D4)

보는 방법

  • 위 「폭」으로 360 · 390 · 412 또는 3폭, 「화면」으로 밝게 · 어둡게.
  • 상태 탭 A~F → 그 안의 작은 버튼으로 세부 상태. F 「직접 해 보기」에서 지난 질문 열기 · 쪽 넘기기 · 제목 바꾸기 · 삭제 · 휴대폰 뒤로가기(흉내)를 직접 눌러 볼 수 있다.
  • 결정 패널에서 고르면 위 화면이 바뀐다. 맨 아래 「내 선택 요약」의 승인 문장을 답장에 붙여 주세요.
  • 이 데모에 없는 부분(답 모양 · 입력 바 · 마이크 · 보내는 범위 한 줄 · 빈 대화 안내 말풍선)은 승인된 task-066 v2 그대로다. 질문 · 답은 모두 합성 예시다.
먼저 알아야 할 것
  1. [확실] 제목 바꾸기는 이미 있다 — 대화가 있을 때 ⋯ 메뉴 → 「제목 바꾸기」. 화면 어디에도 제목이 안 보여 찾기 어렵다(빈 대화의 ⋯ 메뉴엔 없음). 이번엔 보이는 자리를 더한다.
  2. [확실] 서버 목록은 지금 「다음 쪽 열쇠(커서)」만 주고 전체 개수를 주지 않는다. 「1 / 3」처럼 몇 쪽 중 몇 쪽인지 보이려면 목록 응답에 전체 개수를 하나 더해야 한다(작은 서버 변경 — D3).
  3. [확실] 지금 시트에는 삭제가 없다 — 대화를 열고 ⋯ 에서 지운다. 시트 행에서도 지우게 할지는 D6.
  4. [확실] 제목은 100자까지(서버 규칙). 처음 제목은 첫 질문 앞부분 30자로 정해진다.

결정 6건 한눈에 (★ = 권고 · 아래 「결정 필요」에서 골라 보면 화면이 바뀜)

  • D1 지금 대화 제목을 어디에 보이나 — ★ A 머리 「질문」 아래 작은 줄 / B 대화 맨 위 제목 줄 / C 머리 제목을 대화 제목으로 / D 화면에 없음(⋯ 메뉴 윗줄만 — 지금)
  • D2 제목을 어디서 정하나 — ★ A 머리 제목 줄 누르기 + 시트 행 ⋯ + ⋯ 메뉴(유지) / B 첫 질문 보낼 때 제목 칸 + ⋯ 메뉴 / C ⋯ 메뉴만(지금). 빈 제목으로 저장하면 — ★ 저장 안 됨(「제목을 적어 주세요」) / 첫 질문 제목으로 되돌림
  • D3 5개씩 쪽 넘기기 모양 — ★ A ‹ 이전 · 1 / 3 · 다음 ›(서버가 전체 개수를 함께 줌) / B 이전 · 다음만(서버 변경 없음) / C 번호 1 2 3
  • D4 지난 질문을 연 뒤 휴대폰 뒤로가기 — ★ A 기록을 늘리지 않음(뒤로 = 질문 탭에 오기 전 화면) / B 늘림(뒤로 = 직전 대화)
  • D5 옛 주소 /ask/〈id〉 — ★ A 탭 화면(/ask?chat=〈id〉)으로 보냄 / B 옛 화면 그대로 둠
  • D6 지난 질문 시트에서 삭제 — ★ A 행 ⋯ 에 「이 대화 삭제」(확인 단계 그대로) / B 넣지 않음(열고 ⋯ 에서 — 지금)

상태

뒤로가기 · 주소 (D4 · D5 — 화면이 아니라 움직임)

D4 ★ A — 지난 질문을 열어도 기록은 한 칸

  1. 1공부 탭
  2. →
  3. 2하단 「질문」 = 빈 대화
  4. →
  5. 3지난 질문 → 「大丈夫」 → 다시 지난 질문 → 「お疲れ様でした」
  6. →
  7. 4휴대폰 뒤로가기 = 공부 탭
  • 대화를 바꿔도 주소만 /ask?chat=〈id〉 로 바꿔 적는다(기록을 쌓지 않음) — 탭 화면 하나 = 기록 한 칸. 사용자가 말한 「뒤로가기 버튼이 있는 게 아니라 기본 챗봇 형태 유지」와 같은 결.
  • ⋯ → 「새 질문 시작」도 같게 바꾼다 — task-066 은 이것만 기록을 쌓아(뒤로가기 = 직전 대화) 두 동작이 다르게 움직였다.
  • 직전 대화로 돌아가려면 「지난 질문」에서 고른다(최근 순이라 1쪽 맨 위 근처).

D4 B — 대화를 바꿀 때마다 기록을 쌓음

  • 휴대폰 뒤로가기 = 직전 대화. 대화 여러 개를 훑어본 뒤 탭을 떠나려면 뒤로가기를 그만큼 여러 번 눌러야 한다.

D5 ★ A — 옛 주소는 탭 화면으로

  1. 1/ask/〈id〉 — 옛 링크 · 북마크 · 근거 카드에서 돌아오기
  2. →
  3. 2서버가 /ask?chat=〈id〉 로 보냄
  4. →
  5. 3탭 화면에서 그 대화(하단 탭 보임)
  • 없는 대화 · 남의 대화면 지금처럼 빈 대화 + 토스트 「대화를 찾을 수 없어요」.
  • 근거 카드로 수업 · 평가에 갔다가 「질문으로」 돌아와도 탭 화면에 온다.
  • 로그인이 풀린 채 옛 주소로 오면 로그인 뒤 탭 화면으로(돌아갈 주소도 새 모양).

D5 B — 옛 화면을 그대로 둠

  • 옛 링크로 들어오면 여전히 ‹ 머리 · 하단 탭 없는 화면이 나온다 — 요청과 어긋나는 화면이 한 갈래 남는다.

결정 필요 (6건 — 고르면 위 화면이 바뀜)

각 항목 ★ 권고 안이 처음에 골라져 있다. 여기서 고른 값은 이 브라우저에만 남고 팀에 전달되지 않는다 — 맨 아래 「내 선택 요약」의 승인 문장을 답장에 붙여 주세요. Leader 초안에서 바뀐 것: D1(★ 를 「머리 「질문」 아래 작은 줄」로 — 새 안) · D4(「새 질문 시작」도 기록을 늘리지 않게 함께) · 새 D6(시트 행에서 삭제 — 지금 시트엔 삭제가 없다).

그대로 쓰는 것 (task-066 v2 와 같음)

  • 하단 「질문」 탭을 누르면 늘 빈 대화(D1=B 확정) · 안내 말풍선 · 예시 칩(누르면 바로 보냄)
  • 글자 바 · 말 바(누르고 말하기 · 밀어서 취소) · [고쳐서 묻기] · 마이크 예외 문구 19가지
  • 입력 바 아래 보내는 범위 한 줄 · 정보 시트(보내기 확인 창 없음)
  • 답 묶음(근거 · 제안 · 예문 히라가나 · 한글) · 대기 3단계 · 실패 · 한도 안내 줄
  • 「지난 질문」 알약 3상태(기본 · 답 만드는 중 · 새 답 도착) · 도착 토스트 한 번 · 지금 대화는 빼고 셈
  • 시트 행 모양(제목 · 시각 · 둘째 줄 · 「지금 대화」 · 「답 만드는 중」 · 「새 답」) · 지금 대화 행을 누르면 시트만 닫힘
  • ⋯ 「질문 메뉴」(새 질문 시작 · 보내는 범위 보기 · 일본어 표시 · 알아듣는 곳 · 이 대화) · 삭제 확인 단계 · 삭제 뒤 빈 대화 + 「대화를 삭제했어요」
  • 없는 대화 → 빈 대화 + 「대화를 찾을 수 없어요」 · 근거 카드 이동 · 스크롤 위치(마지막 질문에 맞춤)

고르지 않아도 바뀌는 작은 것

  • 낱말을 「제목」으로 맞춤 — ⋯ 메뉴 줄은 이미 「제목 바꾸기」인데 빈 대화 안내만 「이름 바꾸기 · 삭제는 없어요」라 「제목 바꾸기 · 삭제는 없어요」로.
  • 제목 바꾸기 칸 아래 글자 수 「18 / 100」과 안내 한 줄(지금은 저장을 눌러야 100자 초과를 안다).
