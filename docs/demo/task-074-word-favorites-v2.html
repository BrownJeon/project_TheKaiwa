    • D1 D 조합 불가 — 「내 단어 + 즐겨찾기」·「기본 단어 + 즐겨찾기」를 화면에서 고를 수 없다. 즐겨찾기 칸 안에서 「내 단어」 뱃지로만 구분한다. 서버는 두 조건을 따로 받으므로 나중에 화면만 바꿔 열 수 있다.
    • D8 B1 을 고르면 라이트 테마에서 켜진 별이 흰 바탕과 2.95:1 — 약시·밝은 햇빛에서 켜짐을 놓칠 수 있다(모양 채움 + 화면 읽기 상태로 보완). B2 는 이 미달이 없지만 다크에서 윤곽이 흰 테두리로 보인다(토큰 ink 가 다크에서 밝은 색).
    • D9 누르는 곳 겹침 — 뱃지 아래쪽과 셋째 줄 숫자 위쪽 일부를 누르면 상세 대신 별이 바뀐다(면적은 「뱃지 아래 별」 표). 실수로 바꿔도 같은 자리를 다시 누르면 된다.
