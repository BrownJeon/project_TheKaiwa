폭
화면

v2 변경: 설명부 줄바꿈 수정만(내용·결정·상태 동일)

먼저 확인해 주세요 — 보내기 전 확인 창을 없애면 지금은 첫 질문 때 뜨는 「선생님에게 보내는 범위」 확인 창이 내 학습 기록 일부가 외부 AI 로 간다는 것을 알리는 유일한 곳이에요. 요청대로 이 확인 창은 어디에도 없어요 — 질문은 누르면 바로 가요. 대신 입력 바 바로 아래에 한 줄(「내 학습 기록 일부가 AI 에 보내져요 · 자세히」)을 늘 두고, ⋯ 메뉴 「보내는 범위 보기」를 남겼어요(결정 D2). 이 한 줄도 빼려면 D2 C 를 골라 주세요.

무엇을 바꾸나

하단 탭 「질문」을 챗봇창으로 바꾼다. 탭을 열면 곧바로 선생님과의 대화와 입력 바가 보이고, 질문은 확인 없이 바로 간다. 묻는 방법은 둘 — 글로 쓰기(한국어로 무엇이든)와 🎤 일본어로 말하기(들었거나 본 일본어 단어·문장을 그대로 말하면 선생님이 뜻·읽기·느낌·예문으로 설명). 🎤 는 회화 탭과 같은 음성 인식·같은 버튼이라 말하는 동안 알아들은 글자가 바로 보인다. 답의 모양(근거·제안·예문 히라가나·한글)은 task-064 에서 승인한 그대로다.

  1. 1탭 열기 = 마지막 대화 + 입력 바
  2. →
  3. 2글 쓰고 ↑ · 또는 🎤 → 누르고 「大丈夫」 → 떼기
  4. →
  5. 3내 말풍선(들린 글) → 선생님 대기
  6. →
  7. 4답(뜻·읽기·느낌·예문)
  • 보내기 전 확인 창(보내는 범위 시트 + 「알겠어요, 보내기」)
  • 맨 위 입력 카드 · 예시 줄 · 지난 질문 목록으로 된 첫 화면(→ 예시는 빈 대화의 안내 말풍선, 지난 질문은 ⋯ 메뉴)
  • 목록의 「답 만드는 중」·「새 답」 표시(→ 답을 기다리는 질문은 늘 지금 대화라 열면 그 자리에서 보임)
  • 🎤 말로 묻기 — 회화의 「누르고 있는 동안 말하기」 그대로 + 버튼 밖으로 손가락을 빼서 떼면 취소(D3) · 떼면 바로 보냄(D4)
  • 입력 바 아래 보내는 범위 한 줄 · 머리 [＋ 새 질문] · 말로 물은 말풍선 아래 [고쳐서 묻기]

보는 방법

  • 위 「폭」으로 360·390·412 또는 3폭, 「화면」으로 밝게·어둡게.
  • 상태 탭(A~H) → 그 안의 작은 버튼으로 세부 상태.
  • 직접 눌러 보기: B 「처음」·D 「대기」. 예시 칩·글·🎤 를 눌러 보면 대화가 그 자리에 쌓인다. 🎤 = 말 모드로 바꾼 뒤 큰 버튼을 누르고 있으면 알아들은 글자가 점선 말풍선에 나오고, 떼면 보낸다. 누른 채로 손가락을 버튼 밖으로 빼서 떼면 취소. 실제 마이크는 쓰지 않는다 — 「말한 내용」을 위에서 고른다.
  • 결정 패널에서 고르면 위 화면이 바뀐다. 맨 아래 「내 선택 요약」 글을 승인 답장에 붙여 주세요.
  • 휴대폰 높이 780px = 주소창이 보이는 S25+ 첫 화면. 질문·답은 모두 합성 예시다.
먼저 알아야 할 것
  1. [확실] 🎤 는 회화 탭과 같은 일본어 실시간 음성 인식이다(앱 = 휴대폰에서, 파일이 없거나 웹이면 서버에서). 일본어 전용이라 한국어로 말하는 질문은 글로 쓴다. 새 서버 경로는 없다.
  2. [확실] 회화에는 말하는 중 취소가 없다 — 손가락이 어디서 떨어지든 보낸다(0.3초 미만 누름만 취소). 질문은 한 번 보내면 취소할 수 없고 답이 끝나야 다음 질문을 보낼 수 있어서 「밀어서 취소」를 더했다(D3).
  3. [확실] 한 사람은 한 번에 한 질문만 진행된다(서버 규칙). 분당 3번·하루 60번 한도.

결정 필요 (6건 — 고르면 위 화면이 바뀜)

각 항목 ★ 권고 안이 처음에 골라져 있다. 여기서 고른 값은 이 브라우저에만 남고 팀에 전달되지 않는다 — 맨 아래 「내 선택 요약」의 승인 문장을 답장에 붙여 주세요. Leader 초안에서 바뀐 것: D2(한 줄을 입력 바 위 → 아래) · D3(회화와 같은 「누르고 있는 동안」 + 밀어서 취소) · D4(바로 보냄 + [고쳐서 묻기]) · D5 없음(일본어 전용 인식이라 언어를 고를 일이 없다) · D6 정해짐(회화 문구 재사용 — 상태 E 탭) · 새 D7(입력 바 두 모드) · 새 D8(표시 바 자리).

가정 · 확인 필요

  • [가정] 일본어 실시간 인식의 속도·정확도는 회화와 같다(같은 경로·같은 모델). 질문 탭에서 따로 재지 않았다.
  • [확인 필요] 앞서 전달된 서버 받아쓰기 실측(섞어 말하기 오류율 등)은 이 용도와 무관해 반영하지 않았다(사용자 정정 2026-10-13).
  • [확인 필요] 「밀어서 취소」는 회화에 없는 몸짓이다 — 승인되면 회화에도 같은 몸짓을 넣을지 후속 개선(IMP)로 묻는다(두 화면 손버릇이 갈리지 않게).
  • [확인 필요] 1자 이하 안 보냄은 회화 규칙 그대로 — 「木」 같은 한 글자 단어는 글로 물어야 한다.
