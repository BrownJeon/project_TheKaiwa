이 데모가 전제한 동작 · 확인 못 한 것

전제한 동작(이견 있으면 알려 주세요)

  • 공유한 글은 주소(URL)·기록(로그)·서버에 싣지 않습니다. 화면에 채운 뒤에는 지금 붙여넣기처럼 이 기기의 임시 초안에만 남고, [이 문장으로 수업 만들기]를 누를 때 지금과 같은 경로로 보냅니다.
  • 한 번 받은 공유는 한 번만 채웁니다. 새로고침해도 띠가 다시 뜨지 않습니다(초안으로만 남음).
  • 앱이 켜져 있을 때 공유가 오면 보던 화면(수업·회화 중이어도)에서 붙여넣기 화면으로 넘어갑니다. 화면의 ‹(주제 고르기로)는 지금과 같고, 기기 뒤로 가기는 보던 화면으로 돌아갑니다. 앱이 꺼져 있었다면 기기 뒤로 가기는 앱을 닫고 카카오톡으로 돌아갑니다.
  • 입력칸에 자동으로 커서를 두지 않습니다 — 키보드가 올라와 글과 버튼을 가리지 않게.
  • 아주 긴 공유(1만 자 넘음)는 앱이 앞 1만 자만 받고, 그 뒤는 상태 C2 와 같습니다(기기 메모리 보호).
  • Lingofy Japanese 는 글 공유에만 공유 목록에 나옵니다. 사진·파일·여러 개 공유에는 목록에 없습니다.

확인 못 한 것

  • 카톡 메시지의 「공유」가 이 폰에서 안드로이드 공유 목록을 띄우는지, 그리고 넘어오는 글에 보낸 사람·시간 같은 머리말이 붙는지(실기기 확인 전). 머리말이 붙으면 글자 수와 일본어 비율이 달라집니다.
  • 수지센세 글의 실제 길이와 한국어 설명 비율. 서버는 일본어 30% 이상만 받습니다 — 한국어 설명이 대부분인 글은 상태 C3 처럼 막힙니다. 실제 글 1~2개를 보면 C2·C3 기본안을 다시 볼 수 있습니다.
  • 로그인 창(Chrome)이 열린 사이 앱이 메모리에서 밀려나는 빈도 — 상태 D 의 「글을 받지 못함」이 얼마나 드문지.
