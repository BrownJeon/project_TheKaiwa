제안: 슬라이더 범위를 넓히고, 기본값(1.0)에서 얼마나 벗어났는지 보이게 한다

  • 속도 0.6~1.2 → 0.5~1.5 · 높낮이 0.8~1.2 → 0.7~1.4 · 억양 0.8~1.2 → 0.6~1.4 · 말투 세기 0~2 → 0~4 (음성 서버 실측 뒤 확정한 값, 한 칸 0.05 그대로)
  • 슬라이더마다 최저 · 기본 1.0 · 최고 눈금을 달고, 기본에서 손잡이까지만 색을 채운다. 값 옆에 방향 말(느리게·빠르게 등)을 붙인다.
  • 말투 세기 슬라이더는 지금 화면에 없다 — 새로 만들지, 어디에 둘지는 결정 D1.
  • 화면에는 목소리 이름·설명만 보인다. 음성을 만드는 내부 기술 이름은 어디에도 나오지 않는다(지금 규칙 그대로).

바뀌지 않는 것

  • 카드 구성·순서(목소리 → 말투 → 들려주는 방식 → 속도·높낮이·억양 → 미리듣기 → 저장). 말투 세기를 넣는 경우만 한 줄 늘어난다.
  • 미리듣기 버튼 하나로 저장 전 값을 그대로 듣는다. 값을 바꾸면 재생 중인 소리는 멈춘다.
  • 이미 저장된 값은 그대로 유효하다 — 막대 위의 위치만 가운데 쪽으로 옮겨 보인다(예: 속도 1.2 → 70% 지점).

어색하게 들렸던 곳은 설정 화면 미리듣기였다(사용자 답변). 이번 작업은 범위 확대만 한다. 회화·오늘의 회화에서의 어색함, 말투 종류 추가는 폰에서 들어 본 뒤 따로 판단한다.

슬라이더 규격

  • 줄 구성: 이름(12.5px) 왼쪽 · 값 오른쪽(15px 굵게, 고정폭 숫자 + 방향 말 12.5px) → 막대 → 눈금 3개(최저 · 기본 1.0 · 최고, 12px).
  • 터치: 입력 높이 44px(막대 6px 위아래로 19px 여유), 손잡이 26px — 흰 바탕 + 강조색 테두리.
  • 채움: 기본(1.0)에서 손잡이까지만 강조색. 1.0 이면 채움이 없어 기본인지 한눈에 보인다. 막대 아래 기본 자리에 작은 눈금선.
  • 한 칸 0.05(지금과 같음). 화살표 키 한 칸, Home·End 양 끝. 화면 읽기: "1.30배, 기본보다 빠르게".
  • 막대 폭은 카드 안쪽 전체(화면 폭 − 60px). 폭별 한 칸 이동 거리는 오른쪽 표.

한 칸(0.05) 이동 거리 — 손잡이가 움직이는 폭 기준
