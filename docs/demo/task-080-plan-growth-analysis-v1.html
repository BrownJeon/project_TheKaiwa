한눈에 — 무엇이 바뀌고, 무엇이 아직 비어 있나

계획표 탭 맨 위에 [달력 | 분석 | 성장] 분절을 두고, 지금 달력 아래에 있는 «분석 · 성장 기록 곧 열려요» 카드를 두 탭으로 바꾼다. 달력·하루 시트·챌린지 카드·하단 탭 5개는 그대로다. 숫자는 모두 가짜(합성)다.

바뀌는 것

  • 계획표 위 분절 [달력|분석|성장] — 단어장 [단어|채택한 교정] 과 같은 모양·같은 동작(주소 이동 링크)
  • 성장 탭: 연속 출석·공부한 날·날마다 띠·주별 공부량·능력 다섯 가지·AI 평가 점수
  • 분석 탭: 선생님이 기록을 읽고 2주 계획을 제안 → 내가 [이 계획으로 시작]을 눌러야 적용
  • 달력 아래 «곧 열려요» 카드 없어짐

적은 데이터에서 지키는 것

  • 사실(출석·횟수)은 첫날부터 보인다
  • 추정(능력 단계·추세·계획)은 기록이 모인 뒤에만 — 그 전엔 «아직 판단하기 일러요(관측 N건)»
  • 모자란 걸 탓하지 않고 «무엇을 하면 쌓이는지»만 말한다
  • 능력 단계는 JLPT 급수와 섞지 않는다(정본 §5-2)

불편한 사실 (데모 하단 개발 메모 근거표)

  • 지금 실제 데이터로는 두 탭이 거의 비어 보인다 — 가장 많은 계정도 9일·평가 0·계획 0
  • 듣고 응답 능력은 기록하는 코드가 아직 없어 계속 비어 있다(③ 화면은 기록이 생긴 뒤를 가정)
  • 대화 유지는 역할극을 끝낼 때만 1건 쌓여 아주 느리게 찬다
  • 수준 이력은 저장된 곳이 없어 이번 범위에서 뺀다(Q5)
  • 회화량은 «기록 남기기»를 고른 대화만 세서 실제보다 적게 보인다

결정 필요 — Q1~Q7 (★ = 디자이너 권고, 고르면 위 휴대폰에 바로 반영되는 것: Q2·Q3·Q6·Q7)
