먼저 알아 두실 것
  1. ‘지금 수준’은 선생님 대화에도 쓰여요. 다른 수준 단어를 넣으려고 설정에서 수준을 바꾸면 선생님 대화 수준도 같이 바뀌어요(코드 확인: 회화 턴 문맥과 프롬프트 머리에 수준이 들어감). 결정 D4 에 대안이 있어요.
  2. 넣은 단어를 한꺼번에 빼는 기능이 없어요. 가장 작은 단계도 630개, 원어민은 3,070개예요. 잘못 넣으면 하나씩 지우거나 보관해야 해요. 결정 D6 에서 넣기 전 확인을 권해요.
  3. ‘원어민’은 JLPT 에 없는 이름이에요. N1 은 JLPT 가장 높은 급수일 뿐 원어민 수준이라는 뜻이 아니에요. 결정 D1 에서 코드 병기를 권해요.

단계 이름과 단어 수

  • 기본 단어 버튼(3곳)이 내 ‘지금 수준’ 단어를 넣고, 문구에 수준 이름과 개수가 들어가요 — 상태 A·B·C
  • 넣기 전 확인 시트(무엇이 들어가고 무엇을 못 되돌리는지) — 상태 D, 결정 D6
  • 결과 문구에 수준 이름 — 상태 D
  • 단어 상세·단어 입력의 수준 표시를 이름 + 코드로 — 상태 E
  • 설정 ‘지금 수준·목표 수준’에 이름 + 도움말 한 줄 — 상태 F, 결정 D2
  • 설정 맨 아래 ‘단어 자료 출처’ 줄(웹·앱 모두) + 출처 시트 — 상태 F, 결정 D5

이 데모가 전제한 동작 · 확인 못 한 것

전제한 동작(이견 있으면 알려 주세요)

  • 버튼의 숫자는 그 단계의 전체 단어 수예요(이미 가진 단어 포함). 실제로 넣은 수와 건너뛴 수는 결과 문구에서 알려요. 예: 기존 50개가 있는 사용자가 초보자를 누르면 「624개를 넣었어요 · 이미 있는 50개는 건너뛰었어요」.
  • 숫자는 화면이 단어 데이터를 싣지 않도록 단계→개수 표에서 와요(데이터 길이와 같은지 시험으로 확인 — 설계 v2 9번).
  • 수준을 아직 모르면(불러오는 중) 기본 단어 버튼을 그리지 않아요. 빈 단어장·오늘 카드는 원래 목록을 다 읽은 뒤에 나와서 기다림이 생기지 않아요.
  • 추가 시트 안에서 누르면 시트를 하나 더 겹치지 않고 같은 시트가 확인 단계로 바뀌어요(‹ 로 돌아감). 넣은 뒤에는 지금처럼 시트가 남고 결과는 토스트.
  • 확인 시트에서 실패하면 시트를 닫지 않고 그 자리에 오류를 보이며 [다시 넣기]를 둬요. 다시 눌러도 같은 단어가 두 번 들어가지 않아요(서버가 건너뜀).
  • 출처 시트의 주소는 글자로만 보여요(누르면 이동하지 않음, 길게 눌러 복사). 앱 화면이 바깥 사이트로 넘어가면 돌아오기 어렵기 때문이에요.
  • 데모의 토스트는 검토를 위해 다음 동작까지 남아 있어요. 실제는 지금처럼 몇 초 뒤 사라져요.
