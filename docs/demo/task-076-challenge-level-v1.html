한눈에 — 무엇이 바뀌나

사용자 요청: 「오늘의 단어와 회화를 생성할 때 챌린지의 난이도에 따라서 생성하고, 챌린지가 없다면 프로필의 목표수준에 맞춰서 생성. 그러려면 챌린지를 설정할 때 목표를 설정할 수 있게」. 착수 지시 「승인할테니 작업 진행해줘」는 이 데모의 승인이 아니다 — 아래 결정(★ 권고)을 보고 따로 승인해 주셔야 구현이 시작된다.

① 챌린지 만들기 — 난이도 고르기 (화면)

  • ③ 「목표」 단계 맨 위에 「어느 난이도로 할까요?」 N5~N1 다섯 칸. 단계 수는 4개 그대로.
  • 처음엔 고른 주제의 난이도가 골라져 있다 — 손대지 않으면 지금과 똑같다.
  • 아래 한 줄로 내 수준·내 목표·이 주제를 같이 보여 주고, 많이 어렵거나 쉬우면 부드럽게 한 줄 안내(막지 않음).
  • 저장은 이미 있는 Challenge.level 칸 — DB 변경 없음.

② 생성 기준 (규칙 — 화면 아님)

  • 기준 수준 T = 진행 중 챌린지가 있으면 챌린지 난이도, 없으면 내 목표, 목표가 없으면 내 수준.
  • 오늘의 회화 수업은 T 로 만든다(지금은 주제 수준).
  • 오늘의 단어: 챌린지 주제 새 단어(AI 생성)와 내 단어장 세트 가중 기준이 T 를 따른다(챌린지가 없을 때 내 단어장 세트는 지금 그대로).
  • 아래 「수준 결정표」에서 경우마다 지금 → 바뀐 뒤를 확인.

③ 보이는 곳 (작은 변화)

  • 확인 단계: 「난이도」 줄이 생기고 주제 줄의 「· N4」는 빠진다.
  • 계획표 챌린지 카드: 「N3 · 10/18 ~ 10/24」 → 「난이도 N3 · …」.
  • 오늘 탭 회화 카드 수준 뱃지에 기준 출처 꼬리표(「N3 · 내 목표」), 챌린지 단어 칩에 난이도.

④ 알아 두실 것 (불편한 사실 먼저)

  • 목표가 지금보다 훨씬 높으면(예: 내 수준 N5·목표 N2) 챌린지가 없을 때 회화 수업이 갑자기 세 단계 어려워진다 — 요청 그대로면 그렇다. 질문 3.
  • 이미 진행 중인 챌린지도 「내 단어장 세트」는 달라질 수 있다(목표가 챌린지보다 어려운 경우 그 단어가 덜 나옴). 회화·새 단어는 그대로. 질문 4.
  • 챌린지 주제 「새 단어」를 바꾸는 것은 Leader 원안(주제 세트 제외)과 다른 designer 의견이다. 질문 2.

결정 표 — D1~D10 · ★ 권고(승인 전)

★ = 권고안(DB 변경 없음). DB 변경 필요 — 별도 승인 표시가 있는 대안은 고르면 멈추고 백업·스키마 승인 절차를 거친다. 아래 라디오를 바꾸면 휴대폰 화면이 바뀐다(규칙 결정 D4~D6 은 화면이 아니라 결정표에 반영).
