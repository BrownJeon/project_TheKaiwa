  4. [확실] 조각 뱃지는 목록 행 · 상세에는 이미 있다(조각이 빈 단어만 안 보임). 추가 · 수정 폼에는 조각 칸이 아예 없다 — 수정 폼도 같은 부품이라 「수준 → 조각」은 수정에도 적용된다(이제 수정은 내 단어만).
