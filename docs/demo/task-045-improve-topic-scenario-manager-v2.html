개발 메모(화면이 받아야 하는 것 — 계약은 Leader·developer)
  • 주제 목록(관리용): 수준 필터 없이 전부(지금 #56 은 학습자 수준 ±1) + 출처(기본·내 버전·내 주제)·상황 수·기본 표현 수·진행 중 챌린지(제목·며칠째)·끝난 챌린지 수.
  • 주제 초안: 주제 한 줄 + 수준 → 주제 정보(이름·일본어 이름·설명) + 기본 표현 8~12개(종류·일본어·읽기·뜻) + 상황 초안 0~2개. 저장 전 서버 행 없음. 상황 초안만 실패한 부분 성공을 따로 알려 줄 것.
  • 저장: 주제 + 표현 + 고른 상황을 한 번에(하나라도 실패하면 아무것도 저장하지 않음).
  • 지우기 미리보기: 이 주제에만 있는 상황 수·제목, 다른 주제에도 있는 상황 수, 진행 중 챌린지(제목·며칠째), 끝난 챌린지 수. 지우기는 한 트랜잭션.
  • 기본 편집(사용자 결정 — 사용자별 사본): 화면은 「내 버전」 여부·고친 날짜·되돌리기만 안다. 기본 주제·상황 지우기 = 그 사용자에게만 숨김 → 숨긴 기본 항목 목록(주제·상황, 함께 숨겨진 기본 상황 수)과 다시 보기.
  • 주제 초안 요청은 새 AI 작업(측정 p50 약 12초·p95 약 14초, 서버 한도 40초): 취소(요청 끊기), 주제가 아니거나 알맞지 않은 입력은 같은 문구의 422 하나(이유를 나눠 알리지 않음), 일시 실패·시간 초과는 502 → 「잠시 문제가 생겼어요. 다시 만들어 볼까요?」. 성공 응답의 warnings(CHUNKS_SHORT·TYPE_THIN_*·DESCRIPTION_MISSING·TITLE_JA_MISSING·TITLE_TRUNCATED)를 「확인해 볼 곳」으로 보여 줌.
  • v2 새 요청 — 첫마디 일본어 만들기: 한국어 첫마디 + 상황(제목·역할·목표)·수준 → 일본어 첫마디(+읽기). 제안만 돌려주고 행은 만들지 않음. 저장 값은 지금과 같은 {ja, ko}. 계약·프롬프트는 Leader·PE.
  • 끝난 챌린지: 저장된 주제 이름을 그대로 보이고 주제 링크만 뺀다(따로 「지움」 표시 없음).
  • 편집 화면 공유: 상황 고치기 경로에 들어온 곳(시나리오 / 관리)을 넘겨 뒤로 가기 대상만 바꾼다.
