한눈에 — 사용자 요청 두 가지와 먼저 알아 둘 사실

「업로드한 화면에서 개선점 2개가 있어 1. 내가 한말에 대해서 한글로 번역한 것도 함께 표기해줘 2. 회화메뉴에 있는 일본어 도우미 기능을 추가해줘. 배치와 기능은 기존에 구현되어있는 회화화면의 배치로 동일하게 구현해줘. 가능하다면 기존에 있는 입력 영역을 공통화하여 재사용할 수도있도록 설계해서 구현해줘」

먼저 알아 둘 사실 (불편한 것부터)

  • 인식이 뒤틀린 말은 번역도 이상한 한국어가 된다. 캡처의 「私はハンコクの進んでいます…」는 「저는 한코쿠의 나아가고 있습니다 …」처럼 옮겨진다. 화면은 인식이 틀렸는지 알 방법이 없다(인식 신뢰도를 받지 않음).
  • 자동 번역은 말할 때마다 AI 를 한 번 부른다(모범 답안과 같게 말하면 0). 저장하지 않으므로 다시 들어오면 다시 부른다 — 같은 문장은 화면 메모리에 기억해 한 번만.
  • 글자 모드 입력창이 좁아지고 모양이 바뀐다: 회화방과 같은 자리에 도우미가 들어가 …, 둥근 22px 입력창이 회화방 입력창(12px)이 된다.
  • 780 높이에서 도우미 판을 열면 본문이 … 로 줄어든다(판 최대 높이는 회화방과 같은 320px). 과제 문장은 보이지만 목표 표현 칩·모범 답안은 밀어 올려 봐야 한다.

1 · 「내가 한 말」 한국어 뜻 (IMP-0053)

  • 말풍선 안 한글 발음 줄 아래에 구분선 + 뜻 — 회화방 내 말 번역 칸과 같은 모양·문구.
  • 모범 답안과 같게 말하면 모범 답안 뜻을 바로(로딩·비용 0), 다르면 AI 번역 한 번(저장 안 함).
  • 실패해도 말하기·다음 과제는 그대로 — 칸 안에 「번역을 가져오지 못했어요 · 다시 가져오기」.
  • 번역 줄 때문에 말풍선이 … 높아진다.

2 · 일본어 도우미 + 입력 영역 공통화 (IMP-0054)

  • 회화방 §22-2 와 같은 자리: 말 모드 = 바 우측 끝 「가あ」(■ 는 마이크 오른쪽 12px), 글자 모드 = 🎤 오른쪽. 판은 입력 영역 위, 카드도 같다(글자 모드에만 [입력창에 넣기]).
  • 말 바 = 회화방 VoiceBar 그대로(레슨 문구만 다름), 글자 바 = 회화방 Composer, 도우미 부품 공유 — 아래 「공통 입력 영역 대조」.
  • 녹음·인식·확인 중엔 잠기고, 답 확인 결과가 오면 판이 닫힌다(회화방의 「보내면 닫힘」과 같은 규칙).

A1 화면번역 시점A 자동·비차단 — 「내가 한 말」이 뜨면 곧바로 요청, 칸은 「번역 중…」 → 뜻. 말하기·다음 과제를 막지 않는다B 눌러서 보기 — 칸에 [번역 가져오기](회화방 지난 말과 같은 단추)A 는 다시 말할 때마다 호출 1회(과제 3개 × 시도 수). 다시 들어오면 다시 부른다(저장 안 함, L1) — 같은 글은 화면 메모리에 기억. B 는 호출이 줄지만 한 번 더 눌러야 하고 「함께 표기」 요청과 멀다.

A3 화면표시 스위치A 「번역」 표시 스위치와 무관하게 늘 보임B 스위치를 따름⑤ 모범 답안 뜻·회화방 도우미 카드 뜻이 이미 스위치와 무관하다. B 는 ⑤ 에 표시 도구 줄이 없어 끈 사람은 켤 방법이 없다.

C 는 ⑤ 안 다른 뜻 줄(모범 답안 상자)과 모양이 달라지고, 회화방과도 다르다. D 는 말풍선 바탕 밖이라 누구 말의 뜻인지 덜 붙어 보인다. 높이는 실측 표.
