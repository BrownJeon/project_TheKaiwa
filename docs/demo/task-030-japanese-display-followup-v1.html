1표시 바 토글 — 손가락이 닿는 높이 41px → 44px

회화방·채팅방 머리 아래 표시 바의 [히라가나][한글][번역]. 눈에 보이는 알약(32px)은 그대로 두고, 손가락이 닿는 영역만 바 전체 높이(44px)까지 넓혀요. 겉모양은 바뀌지 않아요.

측정(이 화면에서 계산)

운영 화면 QA 실측(10-04, 360·390·412 모두): 현재 41px. 계산은 토글의 터치 영역과 바가 잘라 내는 범위를 겹쳐서 구했어요.

손가락이 닿는 영역바에 잘려 닿지 않는 부분

무엇이 다른가

  • 현재: 바 높이 44px 중 아래 1px 가 테두리라 안쪽은 43px. 바는 가로로 밀리는 상자라 위아래로 넘친 터치 영역이 잘려요.
  • 제안: 아래 선을 바 안쪽에 그리는 1px 선으로 바꿔(같은 색·같은 자리) 안쪽을 44px 로. 토글 터치 영역은 알약 위아래로 7px 씩(46px) 넓혀, 바 안에서는 바 전체 44px 를 써요.
  • 겉모양: 바뀌지 않아요. 바 높이 44 · 선 색과 두께 · 알약 크기 그대로(알약이 0.5px 아래로, 눈으로는 구분되지 않음).
  • 단어장·오늘의 회화 도구 줄의 같은 토글도 겉모양 그대로, 터치 영역만 46px.

2번역 켬 · 내 말풍선 — 읽기 분석이 도착할 때 높이 변화 +5.5px → 4px 이하

채팅방에서 번역을 켠 채 내 말을 보낸 직후. 한글 줄 자리에 막대가 보이다가, 분석이 오면 한자 위 히라가나와 한글 줄로 바뀌어요. 이때 말풍선이 커지는 양을 줄여요. 막대 모양은 그대로예요.

번역(앱 설정)

내 말풍선 높이(이 화면에서 잰 값)

운영 화면 QA 실측(10-04): 번역 켬 +5.5px(3종 말풍선 모두) · 번역 끔 +1.5px. 기준은 4px 이하. 글꼴에 따라 루비가 붙을 때 본문이 1~2px 커지는 양은 기기마다 조금 달라요.

왜 5.5px 인가

현재 · 도착 전
막대 위 여백 6 + 막대 12 + 아래 여백 4. 바로 아래 번역 칸의 위 여백 8 과 겹쳐 아래 4 가 사라짐 → 18px
현재 · 도착 후
한글 줄 위 여백 2 + 줄 19.5 = 21.5px → +3.5, 루비가 붙으며 본문 +2 → +5.5
제안 · 도착 전
막대 자리를 한글 줄과 같은 21.5px(위 2 + 19.5, 막대 12 는 가운데)로, 아래 여백 없음 → 번역 칸이 있어도 그대로
제안 · 도착 후
자리 차이 0, 루비 몫 약 +2 만 남음

적용은 내 말풍선(번역 켬)만이에요. 선생님 말풍선·교정 카드·제안 카드는 지금 그대로(이미 4px 이하).

3회화방 · 표시 설정 저장 실패 알림 — 음성 입력 바를 가리지 않게

표시 바에서 스위치를 눌렀는데 저장이 실패하면 값이 되돌아가고 “표시 설정을 저장하지 못했어요. 다시 눌러 주세요”가 2.2초 떠요. 회화방에서는 이 알림을 방의 다른 알림과 같은 자리·같은 규칙으로 띄워요. 문구와 시간은 그대로예요.

상황

겹침(이 화면에서 계산)

음성 입력 바 = 상태 줄 24 + 말하기 버튼 줄 72 + 위아래 여백 = 116px. 알림은 탭을 막지 않아요(지금도 제안도 손가락이 그대로 아래 버튼에 닿음).

알림이 입력 바를 가리는 부분

무엇이 다른가

    결정 사항

    없음이번 데모에는 고르실 것이 없어요. 세 곳이 이렇게 보이는지만 확인해 주세요.

    세 곳 모두 이미 정해 둔 기준(토글 터치 44px · 분석 도착 때 말풍선 높이 변화 4px 이하 · 회화방 알림 자리와 녹음 중 미루기)에 맞추는 보정이에요. 회화방 알림 자리(아래에서 136px)와 녹음 중 미루기는 회화방이 지금 쓰는 값을 그대로 따르고, 새 수치는 없어요.

    겉모양이 바뀌는 곳

    1·2: 없음(손가락 영역과 기다리는 동안의 자리만). 3: 회화방 음성 모드에서 저장 실패 알림이 뜨는 높이만 바뀌어요. 회화방 글자 입력 모드와 다른 화면(설정·단어장·오늘의 회화 등)의 알림 자리는 지금과 같아요.

    이 데모에 없는 것(같은 작업, 화면 구조 변화 없음)

    한글 줄 글자 보정: 장음 뒤 조사 へ 가 앞 장음에 붙던 것(先生へ 센세-- → 센세-에, 家へ 이에- → 이에에) · 저장 실패 때 방금 띄운 성공 알림을 지우는 동작의 테스트 · 겹친 재요청이 재시도 횟수를 두 번 쓰던 것. 모두 글자나 내부 동작만 바뀌어 화면 배치는 그대로예요.
