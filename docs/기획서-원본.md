# 일본어회화 앱

> 한 줄 정의: 일본어 회화를 훈련하기 위한 모바일 앱으로써 AI와 대화하고 내가 말하는것에 대한 교정도 받으면서 회화를 잘하기 위해 만들어진 앱.

메뉴구성
1. AI와 공부하기
  1) 회화: AI와 직접 말하면서 회화를 하고 잘못된 표현은 AI가 교정해주면서 실제 원어민과 대화하는 훈련을 하는 기능
  2) 채팅: AI와 일상 채팅을 통해서 말한 것에 대한 글자를 입력해보고 올바른 표현에 대하여 점검받는 기능
2. 오늘의 공부
  1) 오늘의 단어: 사전에 등록한 단어장을 랜덤으로 생성하여 단어의 뜻을 맞추는 것으로 생성 개수에 따라서 맞춘개수와 틀린개수, 보관하는 기능을 구현. 기존의 주짓수일상 프로젝트의 '픽미업'메뉴의 카드 생성 및 방식을 참고
  2) 오늘의 회화: 주제를 선택하여 관련된 회화내용을 학습할 수 있도록 함. 학습한 내용은 날마다 기록하여 3일에 한번씩은 학습했는 내용을 섞어서 반복학습을 진행. 진행에 대한 커리큘럼은 강사 에이전트를 정의하여 스케쥴링 및 커리큘럼을 구성하도록 함
  3) AI평가: 단어/회화를 선택하고 주제를 선택해서 강사 에이전트가 사용자를 난이도별로 평가하고 기록
3. 공부계획표
  1) 달력: 앱을 켰을 때에 출석하는 기능을 넣어서 달력에 학습여부와 학습내용에 대한 것을 기록
  2) 분석:  다른 메뉴들에서 회화 및 공부한 내용을 강사 에이전트가 분석하여 공부계획서를 데이터화함.
  3) 성장기록: 평가메뉴에서 평가한 결과 및 매일 학습한 내용에 대한 기록을 저장
4. 서랍장
  1) 단어장: 공부하면서 저장한 단어를 기록
5. 프로필
  1) 기본정보
  2) 목표 (난이도, 주제, 달성기간)
  3) AI설정
6. 무엇이든 물어보세요
  1) 챗봇화면을 통해서 강사 에이전트에게 자유롭게 질의 및 응답을 받는 기능 (주짓수일상에서의 '관장님께 물어보세요' 기능을 참고

## Context

일본어 학습자는 문법·단어 암기 중심 학습으로 읽기는 되지만 말하기·듣기가 안 되는 인풋-아웃풋 불균형 문제를 겪는다. 최근 생성형 AI가 발음·문법 교정과 1:1 맞춤 수업을 무료 수준으로 제공할 수 있게 되면서, 학원 없이도 매일 실전 회화 훈련이 가능한 환경이 마련되었다. 본 앱은 이런 흐름을 반영해 AI 회화·교정·개인화 커리큘럼을 모바일에서 하나로 묶는 것을 목표로 한다.

### 레퍼런스에서 확인한 것
- 레퍼런스1: 조각(이름·액션·느낌·꾸밈) 단위 학습과 5단계 로드맵(문장 수집→조립→즉석 조합→준비된 통화→자유 대화)으로 3개월 내 회화가 가능하다고 주장. 조각 분류·조립·통화 예약 기능의 근거가 됨.
- 레퍼런스2: 흘려듣기(5~10분 반복 청취)와 어순 동일성을 이용한 조각 결합으로 듣기·말하기를 동시에 늘리는 방법을 제시. 오늘의 회화 콘텐츠 설계와 리듬 인식 훈련의 근거가 됨.
- 레퍼런스3: 자막 문장을 3가지 기준으로 선별해 AI(클로드)에 붙여넣으면 발음·문법·문제·말하기 연습까지 30초 내 자동 생성되는 1:1 과외 방식을 제시. AI평가·오늘의 회화 자동 생성 기능의 근거가 됨.

## 핵심 참고자료

**10년차 통역사가 말하는 일본어 60일안에 잘 하는 현실적인 공부 방법**
- 핵심 주장: 문법 암기 대신 조각(이름·액션·느낌·꾸임) 조합으로 회화 능력을 키울 수 있다.
- 방법: 하고 싶은 말 5문장→AI 번역·조각 분류(2주)→조립+AI 교정(4주)→즉석 조립(1개월)→원어민 통화(1개월)→자유 대화.
- 기획 반영: [기능] 오늘의 단어·회화 학습 시 문장을 조각 단위로 분류·저장(출처: 10년차 통역사가 말하는 일본어 60일안에 잘 하는 현실적인 공부 방법). [데이터] 조각 누적 라이브러리 구조.
- 문서에 없는 것: 정확한 AI 프롬프트 전문, '전화1번' 서비스 구조, 난이도 진단 방식.

**이대로만 따라하세요! 일본어가 자동으로 들립니다**
- 핵심 주장: 흘려듣기 반복과 조각 결합 말하기로 문법 없이도 듣기·말하기가 함께 는다.
- 방법: 5~10분 흘려듣기→들린 단어 메모→AI로 뜻 조회→전날 구간 복습 후 새 구간 이어듣기, 매일 20~30분.
- 기획 반영: [기능] 오늘의 회화에서 짧은 청취 구간 반복+단어 메모 저장(출처: 이대로만 따라하세요! 일본어가 자동으로 들립니다). [UI] 완결감 대신 "조금 아쉬운" 종료 지점 설계.
- 문서에 없는 것: 콘텐츠 수급 기준, 전화 일본어 가격·운영, 수준별 커리큘럼 차별화.

**전부 무료입니다. 방구석에서 3개월만에 일본어 마스터하는 방법**
- 핵심 주장: 자막 문장을 AI에 붙여넣으면 발음·문법·문제·말하기 연습이 담긴 1:1 수업이 자동 생성된다.
- 방법: 랭귀지 리액터로 자막 문장 3기준 선별 저장→AI 프로젝트에 과외 지침 등록→문장 붙여넣기만으로 수업 생성, 하루 2문장.
- 기획 반영: [기능] AI평가·오늘의 회화 자동 생성(이해→문법→문제→응용→말하기 순서)(출처: 전부 무료입니다. 방구석에서 3개월만에 일본어 마스터하는 방법). [리스크] 통암기 방지 장치 필요.
- 문서에 없는 것: 복습 스케줄링 방식, 발음 평가 기능, 서비스화 가격 정책.

## 목표·성공 기준

- 목표1: AI와의 회화·채팅으로 실전 표현 교정을 받아 말하기 자신감을 높인다.
- 목표2: 매일 학습(단어·회화)과 3일 주기 반복학습으로 습관을 형성한다.
- 목표3: 강사 에이전트의 평가·분석으로 개인 맞춤 커리큘럼을 제공한다.

| 기준 | 수치 |
|---|---|
| 회화 세션당 교정 응답 시간 | 5초 이내 |
| 주간 연속 출석률(달력 체크) | 베타 사용자 60% 이상 |
| 오늘의 단어 1세트 소요 시간 | 3분 이내 |
| AI평가 완료 후 결과 기록률 | 100%(누락 없음) |

범위 밖 한 줄: 이번 기획에서는 실시간 음성 발음 정밀 채점(피치·억양 스코어링)은 다루지 않는다.

## 대상 사용자·시나리오

대상: 일본어 초~중급 학습자 중 회화·듣기에 약점을 느끼고, 학원 없이 매일 짧게 AI로 실전 훈련하고 싶은 1인 학습자.

- 시나리오A: 출퇴근 지하철에서(언제·어디서) 오늘의 단어 카드 10개를 랜덤으로 풀며(무엇을) 짧은 자투리 시간을 채운다.
- 시나리오B: 저녁 집에서 AI와 음성 회화 세션을 진행하며 잘못된 표현을 즉시 교정받고 채팅으로 다시 타이핑해 복습한다.
- 시나리오C: 주말에 AI평가로 그동안 배운 단어·회화 주제를 난이도별로 진단받고, 분석 탭에서 다음 주 학습계획을 확인한다.

## 핵심 기능

| 기능 | 무엇을 | 왜 | 입력→처리→출력 |
|---|---|---|---|
| AI 회화 | 음성으로 AI와 대화, 오류 실시간 교정 | 원어민 대화 훈련(레퍼런스1 4~5단계) | 음성 발화→STT+AI 교정 판단→교정 자막+음성 응답 |
| AI 채팅 | 텍스트로 대화 후 표현 점검 | 타이핑 표현 교정(레퍼런스2 조각 결합) | 사용자 텍스트→AI 문법·뉘앙스 검사→교정본+설명 |
| 오늘의 단어 | 단어장 랜덤 카드로 뜻 맞추기 | 반복 노출로 어휘 암기(주짓수일상 픽미업 참고) | 단어장 선택→카드 셋 생성→정답/오답 집계·보관 |
| 오늘의 회화 | 주제별 회화 학습+3일 주기 반복 | 인풋-아웃풋 균형, 커리큘럼화(레퍼런스1,3) | 주제 선택→강사 에이전트 생성→학습기록 저장·재출제 |
| AI평가 | 단어/회화 주제 선택 후 난이도 평가 | 수준 진단 및 성장기록 근거 마련(레퍼런스3) | 주제+범위 선택→강사 에이전트 문답→점수·기록 저장 |

이후(조건):
- 원어민 실시간 화상·음성 통화 연동: AI평가 데이터가 충분히 쌓이고 만족도가 낮게 나오는 시점에 검토.
- 발음 정밀 채점(피치 분석): 음성 인식 정확도·비용 검증 후 도입.
- 커뮤니티/랭킹: MAU가 안정적으로 확보된 이후 검토.

## 데이터 모델

| 엔티티 | 핵심 필드 | 관계 |
|---|---|---|
| User | 프로필, 목표(난이도/주제/기간), AI설정 | 1:N StudyLog, WordEntry |
| WordEntry | 단어, 뜻, 등록일, 오답횟수 | User 1:N, 오늘의 단어 카드 생성 소스 |
| ConversationTopic | 주제명, 난이도, 조각(이름/액션/느낌/꾸밈) | Topic 1:N StudyLog |
| StudyLog | 날짜, 유형(회화/채팅/단어), 결과, 교정내용 | User·Topic 참조, 달력·분석 소스 |
| Evaluation | 평가유형, 난이도, 점수, 강사 코멘트 | User 1:N, 성장기록 소스 |

삭제 정책: 사용자가 단어·기록을 삭제해도 집계용 통계는 스냅샷으로 보존해 성장기록 왜곡을 막는다. 확장 여지: ConversationTopic에 콘텐츠 소스(레퍼런스2의 흘려듣기 구간 등) 필드를 추후 추가할 수 있도록 스키마를 유연하게 둔다.

| AI 채팅 점검 | 사용자 타이핑 텍스트 | 올바른 표현+뉘앙스 | LLM, 5초 | 오류만 표시, 원문 임의 수정 금지 |
| 강사 에이전트 커리큘럼 | 학습 이력, 목표 | 오늘의 회화 주제·반복 스케줄 | LLM, 10초(비동기) | 제안 커리큘럼은 사용자 확인 후 저장 |
| AI평가 | 선택 주제+범위, 응답 | 난이도 점수+코멘트 | LLM, 10초 | 평가 근거를 함께 제시해 신뢰도 확보 |
| 무엇이든 물어보세요 | 자유 질문 | 강사 에이전트 답변 | LLM, 5초 | 답변에 확신 없으면 불확실성 명시 |

원칙: AI는 항상 제안만 하며, 학습 기록·단어장 반영은 사용자가 확인(채택)한 뒤에만 저장한다.

## 범위 밖

- 원어민 화상·음성 실시간 통화 연동: 매칭·통역 품질과 비용 검증이 선행돼야 해 이번엔 제외, AI평가 데이터가 쌓인 뒤 재검토.
- 발음 피치·억양 정밀 채점: STT 정확도만으로는 부족해 별도 음성 분석 엔진이 필요, 사용자 피드백 확인 후 검토.
- 커뮤니티·랭킹 기능: 초기에는 개인 학습 루프 완성에 집중, 활성 사용자 확보 후 재검토.
